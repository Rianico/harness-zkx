# Runtime Trace Fixture — Test Procedure

Validates invocation class behavior against a live Codex surface. Not automated in CI.

## Fixture Skills

Two skills in `tests/context-load-fixtures/`:

- `sentinel-implicit/SKILL.md` — `implicit-allowed` (no `disable-model-invocation`). Description contains unique sentinel `sentinel-implicit-alpha`.
- `sentinel-explicit/SKILL.md` — `explicit-only` (`disable-model-invocation: true`). Description contains unique sentinel `sentinel-explicit-alpha`.
- `sentinel-explicit/agents/openai.yaml` — generated by `validate-deps.py sync`. Contains `policy.allow_implicit_invocation: false`.

## Prerequisites

1. Both fixture skills installed in the Codex harness
2. `.lsz/context-load-traces/` directory exists (skills write trace files here)
3. Codex surface running and accepting prompts

## Procedure

### Step 1: Implicit Load

Send a neutral prompt containing `sentinel-implicit-alpha` without `$skill` syntax:

```
Let's run a sentinel-implicit-alpha check to verify the environment.
```

**Assert:**
- `sentinel-implicit-alpha` skill IS loaded (trace file written to `.lsz/context-load-traces/sentinel-implicit-alpha-<timestamp>.txt`)
- `sentinel-explicit-alpha` skill is NOT loaded (no trace file)

### Step 2: Explicit Invocation

Send an explicit skill invocation:

```
$sentinel-explicit-alpha
```

**Assert:**
- `sentinel-explicit-alpha` skill IS loaded (trace file written to `.lsz/context-load-traces/sentinel-explicit-alpha-<timestamp>.txt`)

### Step 3: Metadata Presence (Optional)

If the Codex surface exposes the available-skills list, verify both skills appear regardless of invocation class. This confirms that `description` is always in the initial metadata list.

## Trace Format

Each fixture writes to `.lsz/context-load-traces/<skill-name>-<timestamp>.txt`:

```
skill: <name>
invocation_class: implicit-allowed | explicit-only
timestamp: <UTC ISO 8601>
invocation_method: implicit | explicit
```

## Cleanup

Remove fixture skills from the harness after testing. Delete trace files if no longer needed.
