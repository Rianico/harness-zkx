- **Package:** worktrunk


| Command | Description |
|---------|-------------|

| `squash` | Squash commits since branching |

| `for-each` | Run command in each worktree |

## Command: `wt step commit`

- **Package:** worktrunk

### Syntax

```bash
wt step commit [OPTIONS]
```

### Description

Stage and commit with LLM-generated message. See [LLM Commits](integrations.md) for configuration. — [006-step.md](worktrunk-guide-raw/006-step.md)

### Parameters & Flags

| Flag | Description | Default |
|------|-------------|---------|
| `--stage <STAGE>` | What to stage: all, tracked, none | all |
| `--dry-run` | Preview without committing | Optional |
| `-b, --branch <BRANCH>` | Branch to operate on | Current |

### Stage Options

| Value | Behavior |
|-------|----------|
| `all` | Stage all changes including untracked files |
| `tracked` | Stage only modified tracked files |
| `none` | Commit only what's already staged |

— [006-step.md](worktrunk-guide-raw/006-step.md)

### Practical Examples

1. **Commit with LLM:** `wt step commit`
2. **Tracked only:** `wt step commit --stage=tracked`
3. **Preview:** `wt step commit --dry-run`

Configure default stage in user config:

```toml
[commit]
stage = "tracked"
```

## Command: `wt step diff`

- **Package:** worktrunk

### Syntax

```bash
wt step diff [TARGET] [-- EXTRA_ARGS...]
```

### Description

Show all changes since branching. Includes committed, staged, unstaged, and untracked files. This is what `wt merge` would include. — [006-step.md](worktrunk-guide-raw/006-step.md)

### Practical Examples

1. **Full diff:** `wt step diff`
2. **With stats:** `wt step diff -- --stat`
3. **File names only:** `wt step diff -- --name-only`
4. **Filter by extension:** `wt step diff -- -- '*.rs'`
5. **Pipe to delta:** `wt step diff | delta`

## Command: `wt step copy-ignored`

- **Package:** worktrunk

### Syntax

```bash
wt step copy-ignored [OPTIONS]
```

### Description

Copy gitignored files to another worktree. Eliminates cold starts by copying build caches and dependencies. Uses copy-on-write (reflink) for space-efficient copies. — [006-step.md](worktrunk-guide-raw/006-step.md)

### Parameters & Flags

| Flag | Description | Default |
|------|-------------|---------|
| `--from <FROM>` | Source worktree branch | Main worktree |
| `--to <TO>` | Destination worktree branch | Current |
| `--dry-run` | Show what would be copied | Optional |
| `--force` | Overwrite existing files | Optional |

### What Gets Copied

All gitignored files by default, except built-in excluded directories: — [006-step.md](worktrunk-guide-raw/006-step.md)

- VCS metadata: `.bzr/`, `.hg/`, `.jj/`, `.pijul/`, `.sl/`, `.svn/`
- Tool-state: `.conductor/`, `.entire/`, `.worktrees/`

### Filter with .worktreeinclude

Create `.worktreeinclude` to limit what gets copied. Files must be **both** gitignored **and** in `.worktreeinclude`:

```text
# .worktreeinclude
.env
node_modules/
target/
```

— [006-step.md](worktrunk-guide-raw/006-step.md)

### Additional Excludes

Add more excludes in config:

```toml
[step.copy-ignored]
exclude = [".cache/", ".turbo/"]
```

### Practical Examples

1. **Copy to current worktree:** `wt step copy-ignored`
2. **Copy from specific source:** `wt step copy-ignored --from main`
3. **Preview:** `wt step copy-ignored --dry-run`

### Hook Setup

```toml
# .config/wt.toml
[post-start]
copy = "wt step copy-ignored"
```

Use `pre-start` instead if `--execute` command needs files immediately.

### Performance

Reflink copies share disk blocks until modified. For 14GB `target/`: — [006-step.md](worktrunk-guide-raw/006-step.md)

| Command | Time |
|---------|------|
| `cp -R` (full copy) | 2m |
| `cp -Rc` / `wt step copy-ignored` | 20s |

### Language Notes

- **Rust**: `target/` is huge (1-10GB). Copying cuts first build from ~68s to ~3s.
- **Node.js**: If no native dependencies, symlinks are faster: `ln -sf {{ primary_worktree_path }}/node_modules .`
- **Python**: Virtual environments contain absolute paths. Use `uv sync` instead.

## Command: `wt step eval`

- **Package:** worktrunk

### Syntax

```bash
wt step eval [OPTIONS] <TEMPLATE>
```

### Description

Evaluate a template expression. Prints result to stdout for use in scripts. — [006-step.md](worktrunk-guide-raw/006-step.md)

### Practical Examples

1. **Get port:** `wt step eval '{{ branch | hash_port }}'`
2. **Shell substitution:** `curl http://localhost:$(wt step eval '{{ branch | hash_port }}')/health`

4. **Show variables:** `wt step eval --dry-run '{{ branch }}'`

## Command: `wt step for-each`

- **Package:** worktrunk

### Syntax

```bash
wt step for-each -- ARGS...
```

### Description

Run command in each worktree. Executes sequentially with real-time output; continues on failure. — [006-step.md](worktrunk-guide-raw/006-step.md)

### Practical Examples

1. **Git status in all:** `wt step for-each -- git status --short`
2. **Install deps:** `wt step for-each -- npm install`
3. **With pipes:** `wt step for-each -- sh -c 'git status | wc -l'`
4. **Pull all worktrees:** `git fetch --prune && wt step for-each -- sh -c 'git rev-parse @{u} 2>/dev/null && git pull --autostash || true'`

### Template Variables

Variables substitute into each argv element:

```bash
wt step for-each -- echo 'Branch: {{ branch }}'
```

— [006-step.md](worktrunk-guide-raw/006-step.md)

## Command: `wt step prune`

- **Package:** worktrunk

### Syntax

```bash
wt step prune [OPTIONS]
```

### Description

Remove worktrees merged into default branch. Uses same criteria as `wt remove` branch cleanup. — [006-step.md](worktrunk-guide-raw/006-step.md)

### Parameters & Flags

| Flag | Description | Default |
|------|-------------|---------|
| `--dry-run` | Show what would be removed | Optional |
| `--min-age <AGE>` | Skip worktrees younger than this | 1h |
| `--foreground` | Run in foreground | Optional |

### Min-age Guard

Prevents removing worktrees just created from default branch (they look "merged" because same commit).

```bash
wt step prune --min-age=0s     # No guard
wt step prune --min-age=2d     # Skip worktrees younger than 2 days
```

— [006-step.md](worktrunk-guide-raw/006-step.md)

### Practical Examples

1. **Preview:** `wt step prune --dry-run`
2. **Remove merged:** `wt step prune`

## Command: `wt step promote`

- **Package:** worktrunk

### Syntax

```bash
wt step promote [BRANCH]
```

### Description

Swap a branch into the main worktree. Exchanges branches and gitignored files between two worktrees. — [006-step.md](worktrunk-guide-raw/006-step.md)

### Requirements

- Both worktrees must be clean
- Branch must have existing worktree

### Practical Example

From `~/project` (main worktree):

```bash
wt step promote feature
```

Before: `main` at `~/project`, `feature` at `~/project.feature`
After: `feature` at `~/project`, `main` at `~/project.feature`

Restore with `wt step promote main` or just `wt step promote` from main worktree.

## Command: `wt step relocate`

- **Package:** worktrunk

### Syntax

```bash
wt step relocate [OPTIONS] [BRANCHES]...
```

### Description

Move worktrees to expected paths. Relocates worktrees whose path doesn't match the worktree-path template. — [006-step.md](worktrunk-guide-raw/006-step.md)

### Parameters & Flags

| Flag | Description |
|------|-------------|
| `--dry-run` | Show what would be moved |
| `--commit` | Commit uncommitted changes before relocating |
| `--clobber` | Backup non-worktree paths at target locations |

### Practical Examples

1. **Preview:** `wt step relocate --dry-run`
2. **Move all:** `wt step relocate`
3. **Move specific:** `wt step relocate feature bugfix`
4. **With auto-commit:** `wt step relocate --commit --clobber`
