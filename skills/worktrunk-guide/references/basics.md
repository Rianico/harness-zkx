## Command: `wt switch`

- **Package:** worktrunk
- **Shell:** Bash/Zsh/Fish/PowerShell

### Syntax

```bash
wt switch [OPTIONS] [BRANCH] [-- EXECUTE_ARGS...]
```

### Description

Switch to a worktree by branch name; create if needed. Unlike `git switch`, this navigates between worktrees rather than changing branches in place. Worktrees are addressed by branch name; paths are computed from a configurable template. — [001-switch.md](worktrunk-guide-raw/001-switch.md)

### Parameters & Flags

| Flag | Description | Default |
|------|-------------|---------|
| `-c, --create` | Create a new branch | Optional |
| `-b, --base <BASE>` | Base branch for new branch | Default branch |
| `-x, --execute <CMD>` | Command to run after switch | Optional |
| `--clobber` | Remove stale paths at target | Optional |
| `--no-cd` | Skip directory change | Optional |
| `--branches` | Include branches without worktrees (picker) | Optional |
| `--remotes` | Include remote branches (picker) | Optional |

### Shortcuts

| Shortcut | Meaning | Example |
|----------|---------|---------|
| `^` | Default branch (main/master) | `wt switch ^` |
| `@` | Current branch/worktree | `wt switch @` |
| `-` | Previous worktree | `wt switch -` |
| `pr:{N}` | GitHub PR #N | `wt switch pr:123` |
| `mr:{N}` | GitLab MR !N | `wt switch mr:101` |

Shortcuts also apply to `--base`. — [001-switch.md](worktrunk-guide-raw/001-switch.md)

### Practical Examples

1. **Switch to existing:** `wt switch feature-auth`
2. **Create and switch:** `wt switch --create new-feature`
3. **Create from specific base:** `wt switch --create hotfix --base production`
4. **Switch to PR branch:** `wt switch pr:123`
5. **Previous worktree:** `wt switch -`
6. **Create and launch editor:** `wt switch --create fix -x claude -- 'Fix bug #42'`

### Workflow

When creating a new worktree: — [001-switch.md](worktrunk-guide-raw/001-switch.md)

1. Runs `pre-switch` hooks (blocking)
2. Creates worktree at configured path
3. Switches to new directory
4. Runs `pre-start` hooks (blocking)
5. Spawns `post-start` and `post-switch` hooks (background)

### Common Pitfalls

- **Branch doesn't exist** — Use `--create` flag — [001-switch.md](worktrunk-guide-raw/001-switch.md)
- **Path occupied** — Another worktree is at the target path; switch to it or remove it
- **Stale directory** — Use `--clobber` to remove non-worktree directory at target

## Command: `wt list`

- **Package:** worktrunk
- **Shell:** Bash/Zsh/Fish/PowerShell

### Syntax

```bash
wt list [OPTIONS]
wt list statusline
```

### Description

List worktrees and their status. Shows uncommitted changes, divergence from default branch and remote, and optional CI status and LLM summaries. Table renders progressively: branch names appear immediately, then status fills in as git operations complete. — [002-list.md](worktrunk-guide-raw/002-list.md)

### Parameters & Flags

| Flag | Description | Default |
|------|-------------|---------|
| `--format <FORMAT>` | Output format (table, json) | table |
| `--full` | Show CI, diff analysis, LLM summaries | Optional |
| `--branches` | Include branches without worktrees | Optional |
| `--remotes` | Include remote branches | Optional |
| `--progressive` | Show fast info first, update later | Auto for TTY |

### Columns

| Column | Shows |
|--------|-------|
| Branch | Branch name |
| Status | Compact symbols (staged, modified, conflicts, etc.) |
| HEAD± | Uncommitted changes: +added -deleted lines |
| main↕ | Commits ahead/behind default branch |
| Remote⇅ | Commits ahead/behind tracking branch |
| CI | Pipeline status (with `--full`) |
| URL | Dev server URL from config |
| Commit | Short hash (8 chars) |
| Age | Time since last commit |
| Message | Last commit message (truncated) |

### Status Symbols

| Symbol | Meaning |
|--------|---------|
| `+` | Staged files |
| `!` | Modified files (unstaged) |
| `?` | Untracked files |
| `^` | Is the default branch |
| `_` | Same commit as default branch, clean |
| `⊂` | Content integrated into default branch |
| `↕` | Diverged from default branch |
| `⇡` | Ahead of remote |
| `⇣` | Behind remote |

Rows are dimmed when safe to delete (`_` same commit clean or `⊂` integrated). — [002-list.md](worktrunk-guide-raw/002-list.md)

### Practical Examples

1. **Basic listing:** `wt list`
2. **Full info with CI:** `wt list --full`
3. **Include all branches:** `wt list --branches`
4. **JSON for scripting:** `wt list --format=json | jq '.[] | select(.is_current) | .branch'`
5. **Find branches to remove:** `wt list --format=json | jq '.[] | select(.main_state == "integrated") | .branch'`

### JSON Output Fields

Key fields in JSON output: — [002-list.md](worktrunk-guide-raw/002-list.md)

- `branch`, `path`, `kind` (worktree/branch)
- `working_tree.staged`, `working_tree.modified`, `working_tree.untracked`
- `main.ahead`, `main.behind` — relation to default branch
- `remote.ahead`, `remote.behind` — relation to tracking branch
- `main_state` — relation to default branch (is_main, integrated, diverged, etc.)
- `ci.status` — CI status (passed, running, failed, etc.)

## Command: `wt remove`

- **Package:** worktrunk
- **Shell:** Bash/Zsh/Fish/PowerShell

### Syntax

```bash
wt remove [OPTIONS] [BRANCHES]...
```

### Description

Remove worktree; delete branch if merged. Defaults to current worktree. Runs in background by default — command returns immediately, cleanup continues asynchronously. — [003-remove.md](worktrunk-guide-raw/003-remove.md)

### Parameters & Flags

| Flag | Description | Default |
|------|-------------|---------|
| `--no-delete-branch` | Keep branch after removal | Optional |
| `-D, --force-delete` | Delete unmerged branches | Optional |
| `--foreground` | Run removal in foreground | Optional |
| `-f, --force` | Force worktree removal (untracked files) | Optional |

### Force Flags

Two force flags for different situations: — [003-remove.md](worktrunk-guide-raw/003-remove.md)

| Flag | Scope | When to use |
|------|-------|-------------|
| `--force` (`-f`) | Worktree | Worktree has untracked files |
| `--force-delete` (`-D`) | Branch | Branch has unmerged commits |

### Branch Cleanup Criteria

Branches are deleted when they would add no changes to default branch if merged. Checks in order: — [003-remove.md](worktrunk-guide-raw/003-remove.md)

1. **Same commit** — Branch HEAD equals default branch
2. **Ancestor** — Branch is in target's history
3. **No added changes** — Three-dot diff is empty
4. **Trees match** — Branch tree SHA equals target tree SHA
5. **Merge adds nothing** — Simulated merge produces same tree
6. **Patch-id match** — Diff matches a squash-merge on target

### Practical Examples

1. **Remove current:** `wt remove`
2. **Remove specific:** `wt remove feature-branch`
3. **Force untracked files:** `wt remove feature --force`
4. **Delete unmerged:** `wt remove experimental -D`
5. **Keep branch:** `wt remove --no-delete-branch feature`

## Command: `wt merge`

- **Package:** worktrunk
- **Shell:** Bash/Zsh/Fish/PowerShell

### Syntax

```bash
wt merge [OPTIONS] [TARGET]
```

### Description

Merge current branch into target branch. Squash and rebase, fast-forward target, remove worktree. Unlike `git merge`, this merges current into target — not target into current. Similar to GitHub's "Merge pull request" button, but locally. — [004-merge.md](worktrunk-guide-raw/004-merge.md)

### Parameters & Flags

| Flag | Description | Default |
|------|-------------|---------|
| `--no-squash` | Skip commit squashing | Optional |
| `--no-commit` | Skip commit and squash | Optional |
| `--no-rebase` | Skip rebase | Optional |
| `--no-remove` | Keep worktree after merge | Optional |
| `--no-ff` | Create merge commit (semi-linear) | Optional |
| `--stage <STAGE>` | What to stage: all, tracked, none | all |

### Pipeline

`wt merge` runs these steps: — [004-merge.md](worktrunk-guide-raw/004-merge.md)

1. **Commit** — Pre-commit hooks, commit uncommitted changes
2. **Squash** — Combine commits since target into one
3. **Rebase** — Rebase onto target if behind
4. **Pre-merge hooks** — Run after rebase, before merge
5. **Merge** — Fast-forward merge to target branch
6. **Pre-remove hooks** — Run before removing worktree
7. **Cleanup** — Remove worktree and branch
8. **Post-remove + post-merge** — Background cleanup

### Practical Examples

1. **Merge to default:** `wt merge`
2. **Merge to specific:** `wt merge develop`
3. **Keep worktree:** `wt merge --no-remove`
4. **Preserve history:** `wt merge --no-squash`
5. **Create merge commit:** `wt merge --no-ff`

### Local CI Pattern

Pre-merge hooks enable local CI validation: — [004-merge.md](worktrunk-guide-raw/004-merge.md)

```toml
[[pre-merge]]
test = "cargo test"
lint = "cargo clippy"
```
