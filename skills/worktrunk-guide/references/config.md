## Shell Integration

Worktrunk needs shell integration to change directories when switching worktrees. — [005-config.md](worktrunk-guide-raw/005-config.md)

### Install

```bash
wt config shell install
```

Installs to:
- **Bash**: `~/.bashrc`
- **Zsh**: `~/.zshrc`
- **Fish**: `~/.config/fish/functions/wt.fish`
- **PowerShell**: Profile files for both PowerShell 7+ and Windows PowerShell 5.1

### Uninstall

```bash
wt config shell uninstall
```

Without shell integration, `wt switch` prints the target directory but cannot `cd` into it.

## Worktree Path Template

Controls where new worktrees are created. — [005-config.md](worktrunk-guide-raw/005-config.md)

### Template Variables

| Variable | Description | Example |
|----------|-------------|---------|
| `{{ repo_path }}` | Absolute path to repo root | `/Users/me/code/myproject` |
| `{{ repo }}` | Repository directory name | `myproject` |
| `{{ owner }}` | Remote owner path (may include subgroups) | `group/subgroup` |
| `{{ branch }}` | Raw branch name | `feature/auth` |
| `{{ branch \| sanitize }}` | Filesystem-safe (`/` → `-`) | `feature-auth` |
| `{{ branch \| sanitize_db }}` | Database-safe identifier | `feature_auth_x7k` |
| `{{ branch \| codename(2) }}` | Deterministic friendly name | `malleable-opah` |

### Example Templates

```toml
# Default: sibling directory
worktree-path = "{{ repo_path }}/../{{ repo }}.{{ branch | sanitize }}"

# Inside repository
worktree-path = "{{ repo_path }}/.worktrees/{{ branch | sanitize }}"

# Centralized directory
worktree-path = "~/worktrees/{{ repo }}/{{ branch | sanitize }}"

# By remote owner
worktree-path = "~/development/{{ owner }}/{{ repo }}/{{ branch }}"
```

## LLM Commit Messages

Generate commit messages automatically during merge. — [005-config.md](worktrunk-guide-raw/005-config.md)

### Claude Code

```toml
[commit.generation]
command = "CLAUDECODE= MAX_THINKING_TOKENS=0 claude -p --no-session-persistence --model=haiku --tools='' --disable-slash-commands --setting-sources='' --system-prompt=''"
```

### Codex

```toml
[commit.generation]
command = "codex exec -m gpt-5.1-codex-mini -c model_reasoning_effort='low' -c system_prompt='' --sandbox=read-only --json - | jq -sr '[.[] | select(.item.type? == \"agent_message\")] | last.item.text'"
```

### Other Tools

```toml
# OpenCode
command = "opencode run -m anthropic/claude-haiku-4.5 --variant fast"

# llm
command = "llm -m claude-haiku-4.5"

# aichat
command = "aichat -m claude:claude-haiku-4.5"
```

### Template Variables

| Variable | Description |
|----------|-------------|
| `{{ git_diff }}` | Diff content |
| `{{ git_diff_stat }}` | Diff statistics |
| `{{ branch }}` | Current branch name |
| `{{ repo }}` | Repository name |
| `{{ recent_commits }}` | Recent commit subjects |
| `{{ commits }}` | Commits being squashed (squash template only) |
| `{{ target_branch }}` | Merge target (squash template only) |

## Command Configuration

### List Settings

```toml
[list]
summary = false    # LLM branch summaries (requires [commit.generation])
full = false       # Show CI, diffstat, summaries
branches = false   # Include branches without worktrees
remotes = false    # Include remote branches
```

— [005-config.md](worktrunk-guide-raw/005-config.md)

### Merge Settings

```toml
[merge]
squash = true      # Squash commits into one
commit = true      # Commit uncommitted changes first
rebase = true      # Rebase onto target before merge
remove = true      # Remove worktree after merge
verify = true      # Run project hooks
ff = true          # Fast-forward merge
```

— [005-config.md](worktrunk-guide-raw/005-config.md)

### Switch Settings

```toml
[switch]
cd = true          # Change directory after switching

[switch.picker]
pager = "delta --paging=never"
```

— [005-config.md](worktrunk-guide-raw/005-config.md)

## Project Configuration

Project config (`.config/wt.toml`) is checked into version control for team sharing. — [005-config.md](worktrunk-guide-raw/005-config.md)

### Hooks

```toml
# .config/wt.toml
pre-start = "npm ci"
post-start = "npm run dev"
pre-merge = "npm test"
```

### Dev Server URL

```toml
[list]
url = "http://localhost:{{ branch | hash_port }}"
```

URL column shows in `wt list`, dimmed when port not listening.

### Forge Platform

```toml
[forge]
platform = "github"  # or "gitlab", "gitea", "azure-devops"
hostname = "github.example.com"  # For self-hosted instances
```

### Aliases

```toml
[aliases]
deploy = "make deploy BRANCH={{ branch }}"
url = "echo http://localhost:{{ branch | hash_port }}"
```

## State Management

### Command: `wt config state`

| Subcommand | Description |
|------------|-------------|
| `default-branch` | Get/set default branch |
| `previous-branch` | Previous branch for `wt switch -` |
| `logs` | Operation and debug logs |
| `ci-status` | CI status cache |
| `marker` | Branch markers (emoji in wt list) |
| `vars` | Custom variables per branch |

— [005-config.md](worktrunk-guide-raw/005-config.md)

### Default Branch

```bash
# Get default branch
wt config state default-branch

# Set manually
wt config state default-branch set main

# Clear cache and re-detect
wt config state default-branch clear
```

Detection order: Worktrunk cache → Git cache → Remote query → Local inference. — [005-config.md](worktrunk-guide-raw/005-config.md)

### Branch Markers

```bash
wt config state marker set "🚧"
wt config state marker set "✅" --branch feature
```

Markers appear in `wt list` Status column. — [005-config.md](worktrunk-guide-raw/005-config.md)

### Custom Variables

```bash
wt config state vars set env=staging
wt config state vars set config='{"port": 3000}'
wt config state vars get env
```

Access in templates: `{{ vars.env }}`, `{{ vars.config.port }}`. — [005-config.md](worktrunk-guide-raw/005-config.md)

## Environment Variables

Override config with `WORKTRUNK_` prefix. Nested keys use double underscores. — [005-config.md](worktrunk-guide-raw/005-config.md)

| Config | Environment Variable |
|--------|---------------------|
| `worktree-path` | `WORKTRUNK_WORKTREE_PATH` |
| `commit.generation.command` | `WORKTRUNK_COMMIT__GENERATION__COMMAND` |
| `commit.stage` | `WORKTRUNK_COMMIT__STAGE` |

### Other Variables

| Variable | Purpose |
|----------|---------|
| `WORKTRUNK_BIN` | Override binary path |
| `WORKTRUNK_CONFIG_PATH` | Override user config location |
| `WORKTRUNK_PROJECT_CONFIG_PATH` | Override project config location |
| `WORKTRUNK_MAX_CONCURRENT_COMMANDS` | Max parallel git commands (default: 32) |
| `NO_COLOR` | Disable colored output |

## Approvals

Project hooks and aliases require approval on first run. — [005-config.md](worktrunk-guide-raw/005-config.md)

```bash
# Pre-approve all commands for current project
wt config approvals add

# Clear approvals
wt config approvals clear
wt config approvals clear --global
```

Approved commands saved to `~/.config/worktrunk/approvals.toml`. Use `--yes` to bypass prompts in CI.
