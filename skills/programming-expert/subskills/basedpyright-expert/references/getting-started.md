## What is Basedpyright?

Basedpyright is a fast Python static type checker forked from Microsoft's pyright. It adds stricter defaults, new diagnostic rules, improved type narrowing, and a baseline feature for gradual adoption.

Key differentiators from pyright:
- `typeCheckingMode="recommended"` by default (all checks enabled)
- `failOnWarnings=true` in recommended mode
- 13 new diagnostic rules (reportAny, reportExplicitAny, etc.)
- Baseline workflow for gradual adoption
- `.venv` auto-detection
- `pythonPlatform="All"` by default

## Adoption Progression

### Stage 1: Initial Type Checking

1. Install basedpyright (CLI or language server)
2. Create minimal config:
   ```toml
   # pyproject.toml
   [tool.basedpyright]
   include = ["src"]
   ```
3. Run basedpyright with default settings
4. Fix errors and warnings; optionally disable specific rules

### Stage 2: Types for Imported Libraries

1. Update dependencies to typed versions
2. Enable `reportMissingTypeStubs` to find untyped imports
3. Create custom stubs in `typings/` directory
4. Configure `stubPath` in config file

### Stage 3: Incremental Typing

1. Add type annotations to function parameters, instance variables, return types
2. Enable stricter rules: `reportUnknownParameterType`, `reportUntypedFunctionDecorator`

### Stage 4: Strict Typing

1. Add `# pyright: strict` to individual files
2. Or add subdirectories to `strict` config entry

## IDE Commands

### Organize Imports

Reorders imports into three groups (stdlib, third-party, local), sorted alphabetically within each group.

**Note:** Prefer [ruff](https://docs.astral.sh/ruff/formatter/#sorting-imports) for import sorting -- pyright cannot validate sorted imports via CLI.

### Restart Server

Discards cached type information and restarts analysis. Useful after installing new type stubs or libraries.

Source: [basedpyright-expert-raw/009-commands.md](basedpyright-expert-raw/009-commands.md)

## Language Server Features

- Intelligent type completion with auto-imports
- Signature help for function calls
- Hover for type information and docstrings
- Go to definition, find references, rename symbol
- Call hierarchy navigation
- Type stub generation for third-party libraries

## Performance

Basedpyright is optimized for large codebases:
- Lazy/just-in-time type evaluation
- Incremental updates in watch mode
- Graceful recovery from syntax errors
- 3x-5x faster than mypy in many cases

## Limitations

- Python 3.0+ only (no Python 2 support)
- No plugin system (unlike mypy)
- Does not model all import loader side effects
