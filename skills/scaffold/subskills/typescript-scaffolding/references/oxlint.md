## Install & scripts (scaffold wiring)

```bash
pnpm add -D oxlint   # scaffold pins >=1 via package.json devDependencies
```

`package.json` scripts generated by `scaffold.py` (`build_package_json`):

```jsonc
{
  "scripts": {
    "lint": "oxlint .",
    "format": "oxfmt --check .",
    "format:fix": "oxfmt .",
    "typecheck": "tsc --noEmit",
    "test": "vitest run"
  },
  "devDependencies": {
    "oxlint": ">=1",
    "oxfmt": ">=0.15",
    "typescript": ">=7",
    "vite": ">=8",
    "vitest": ">=4",
    "tsx": ">=4",
    "@types/node": ">=24"
    // + "@semantic-release/*", "semantic-release" — see scaffold.py:build_package_json for full list
  }
}
```

> Quickstart convention (not scaffold): `"lint:fix": "oxlint --fix"` — scaffold default is `"lint": "oxlint ."` only (see `scaffold.py:build_package_json`); add alias manually if desired. Fix locally via `oxlint --fix .`.

Run:

```bash
pnpm run lint          # oxlint .
pnpm run lint:fix      # oxlint --fix (if added) or oxlint --fix .
oxlint --fix           # safe fixes
oxlint --fix-suggestions      # may change behavior
oxlint --fix-dangerously      # dangerous fixes
```

Type-aware requires tsgo (TS 7): `oxlint --type-aware`, `--type-check`. See <https://oxc.rs/docs/guide/usage/linter/type-aware>

## Config discovery

Oxlint auto-discovers ONE config per directory (cannot mix JSON + TS):

- `.oxlintrc.json` / `.oxlintrc.jsonc` (JSONC with comments, ESLint v8 compatible)
- `oxlint.config.ts` / `oxlint.config.mts` (requires Node-based `oxlint`, Node 22.18+ or 24+, wrap with `defineConfig`)

Search walks up from cwd. Override:

```bash
oxlint -c ./.oxlintrc.json
oxlint --config ./oxlint.config.ts  # disables nested lookup
oxlint --disable-nested-config      # only cwd lookup
oxlint --init                       # generate starter JSON
```

Scaffold default (`OXLINT_JSON` in `scaffold.py`):

```json
{
  "$schema": "./node_modules/oxlint/configuration_schema.json",
  "rules": {}
}
```

Minimal with category:

```json
{
  "$schema": "./node_modules/oxlint/configuration_schema.json",
  "categories": { "correctness": "warn" },
  "rules": { "eslint/no-unused-vars": "error" }
}
```

TypeScript config:

```ts
import { defineConfig } from 'oxlint';
export default defineConfig({
  categories: { correctness: 'warn' },
  rules: { 'eslint/no-unused-vars': 'error' }
});
```

`$schema` gives editor validation/autocomplete.

## Top-level config fields

| Field             | Purpose                                                                 |
| ----------------- | ----------------------------------------------------------------------- |
| `rules`           | per-rule severity + options                                             |
| `categories`      | enable groups by intent                                                 |
| `plugins`         | built-in plugins (import, react, jest, vitest, unicorn, jsx-a11y, etc.) |
| `jsPlugins`       | ESLint-compatible JS plugins (alpha)                                    |
| `overrides`       | per-glob config                                                         |
| `extends`         | inherit from other files                                                |
| `ignorePatterns`  | additional ignores                                                      |
| `env` / `globals` | predefined / custom globals                                             |
| `settings`        | plugin-wide shared config                                               |
| `options`         | linter-level: `typeAware`, `typeCheck`, `maxWarnings`                   |

Full list → `006-config-file-reference.md` and <https://oxc.rs/docs/guide/usage/linter/config-file-reference>

Example `options`:

```json
{ "options": { "typeAware": true, "typeCheck": true, "maxWarnings": 10 } }
```

## Categories

Ordered left-to-right on CLI; last wins:

`correctness` (default, wrong/useless) · `suspicious` · `pedantic` (strict, occasional false positives) · `perf` · `style` · `restriction` · `nursery` (in development) · `all` (all except nursery, no plugins)

CLI severity toggles:

```bash
-D correctness -A no-debugger      # deny correctness, allow no-debugger
-A all -D no-debugger
-A <NAME> / --allow   # suppress
-W <NAME> / --warn    # warning
-D <NAME> / --deny    # error
```

## Plugins

Enable as flags or via config `plugins`. Built-in (no JS dep tree):

```bash
--import-plugin --react-plugin --jest-plugin --vitest-plugin --jsx-a11y-plugin
--promise-plugin --node-plugin --jsdoc-plugin --nextjs-plugin --vue-plugin
--react-perf-plugin
--disable-unicorn-plugin --disable-oxc-plugin --disable-typescript-plugin
```

Ruleset 500+ rules (ESLint + TypeScript + React/Jest/Vitest/Import/Unicorn/jsx-a11y etc.) — use `oxlint --rules` for exact count. Browse <https://oxc.rs/docs/guide/usage/linter/rules>.

## CLI reference (verify gate relevant)

```
oxlint [-c <config>] [PATH]...
  -c, --config <file>          config path (disables nested lookup)
      --tsconfig <file>         override tsconfig for import resolution (avoid; type-aware ignores it)
      --init                    init config
  -A/--allow <NAME>  -W/--warn <NAME>  -D/--deny <NAME>   category or rule
      --fix / --fix-suggestions / --fix-dangerously
      --ignore-path <PATH>  --ignore-pattern <PAT>  --no-ignore
      --quiet  --deny-warnings  --max-warnings <INT>
  -f/--format <ARG>  default|json|unix|checkstyle|github|gitlab|junit|stylish|sarif|agent
      --threads <INT>  --print-config  --rules  --lsp  --type-aware  --type-check
      --disable-nested-config  --no-error-on-unmatched-pattern  --silent
  PATH  file/dir/glob, default "."
```

Verify gate in scaffold/CI:

```bash
pnpm run lint          # oxlint .
pnpm run lint -- --max-warnings 0
oxlint --print-config src/index.ts   # inspect effective config
```

## Ignore & output

- Ignore via `.eslintignore`, `--ignore-path`, `--ignore-pattern "dist/**"`, or `ignorePatterns` in config.
- Formats for CI: `oxlint -f github` / `json` / `junit` etc.
- `--quiet` (errors only), `--deny-warnings` (warnings → non-zero), `--max-warnings`.

## Notes for scaffold consumers

- Deterministic file is `.oxlintrc.json` with `$schema`; hand-edit allowed after generation (scaffold never hand-copies templates — use `scaffold.py`).
- CI verify job (`ci-scaffolding`) runs `pnpm run lint` as part of `pnpm run lint && pnpm run format && pnpm run typecheck && pnpm test`.
- Migration from ESLint: `npx @oxlint/migrate` and `eslint-plugin-oxlint` for incremental dual-run. See <https://oxc.rs/docs/guide/usage/linter/migrate-from-eslint>
- Variants (SKILL.md): `lib`/`cli`/`pi-extension` — entry changes `main`/`bin`/`pi.extensions`; not lint-specific.
- Coverage: with `--with-coverage` CI swaps `pnpm test` → `pnpm run coverage` (thresholds in `vitest.config.ts`).
