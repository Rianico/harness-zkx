## Decision rules

| When you need to                                    | Do this                                         | Because                                             |
| --------------------------------------------------- | ----------------------------------------------- | --------------------------------------------------- |
| create a branch with custom base                    | `wt switch --create feat --base release`        | `--base` sets the parent, not `git checkout -b`     |
| switch without shell integration                    | `wt switch --no-cd feat` then `cd` manually   | shell integration is required for auto-`cd`         |
| run a command after switch                          | `wt switch --create feat -x claude -- 'prompt'` | `--execute` replaces `wt` with the command          |
| get structured output                               | `wt list --format=json 2>/dev/null`             | JSON stable; stderr may contain schema notices      |
| squash and merge without LLM                        | `wt merge --no-commit` (pre-stage manually)     | skips auto-commit stage                             |
| skip all automation                                 | `--no-hooks` flag                               | blocks both pre- and post- hooks                    |
| approve in CI                                       | `--yes` flag                                    | skips interactive approval prompts                  |
| copy cached deps to new worktree                    | add `post-start` hook: `wt step copy-ignored`   | avoids cold installs on every new worktree          |
| remove worktree, keep branch                        | `wt remove --no-delete-branch`                   | worktree deleted, branch stays in repo              |
| preview removals before executing                   | `wt step prune --dry-run`                        | shows what would change without mutating state      |
| check status across all worktrees                   | `wt step for-each -- git status --short`         | runs command sequentially; continues on failure     |
| create worktree and avoid hooks                     | `wt switch --create feat --no-hooks`             | skips pre-switch, pre-start, post-start hooks       |

## Trade-off matrices

### merge flags: which to use

| Flag            | When to use                                  | Trade-off                                      |
| --------------- | -------------------------------------------- | ---------------------------------------------- |
| `--no-squash`   | preserve individual commits                  | merge history noisier; harder to cherry-pick    |
| `--no-ff`       | trace merge points in history               | extra merge commit clutters log                 |
| `--no-remove`   | keep worktree for follow-up work             | accumulates stale worktrees                    |
| `--no-rebase`   | skip rebase (semi-linear merge)              | risk of mid-air collision with target           |
| `--stage=none`  | only commit already-staged content           | uncommitted changes silently dropped            |

### copy-ignored vs symlink vs fresh install

| Approach           | Speed       | Isolation | Portability | When to use                                    |
| ------------------ | ----------- | --------- | ----------- | ---------------------------------------------- |
| copy-ignored       | Fast (CoW)  | Full      | High        | default for most projects                      |
| symlink            | Instant     | Weak      | Low         | Node without native deps; python static assets |
| fresh install      | Slow        | Full      | High        | CI; when deps changed since last copy          |
| uv sync / npm ci   | Medium      | Full      | Medium      | Python or Node when native modules differ      |

### Where to put config

| Config              | File                               | When                                           |
| ------------------- | ---------------------------------- | ---------------------------------------------- |
| worktree path       | `~/.config/worktrunk/config.toml`  | personal preference, applies to all repos       |
| LLM commit command  | `~/.config/worktrunk/config.toml`  | personal API keys, applies to all repos         |
| project hooks       | `.config/wt.toml`                  | team-shared automation; checked into VCS        |
| dev server URL      | `.config/wt.toml`                  | shown in `wt list`; team-shared                |
| forge platform      | `.config/wt.toml`                  | team-shared for self-hosted instances            |
| CI approvals        | `~/.config/worktrunk/approvals.toml` | auto-generated; per-project hash of hook cmds |

## Tells and smells

### Tells (healthy)

- `wt list` shows every active branch with a worktree.
- Status symbols are green (`_`, `⊂`, `⇡`).
- `wt step prune` shows zero stale worktrees.
- Dev servers auto-start on switch and stop on remove.
- CI column shows pipeline status under `--full`.

### Smells (problems)

| Smell                              | Cause                                        | Fix                                             |
| ---------------------------------- | -------------------------------------------- | ----------------------------------------------- |
| dimmed rows in `wt list`           | branch content merged; worktree safe to delete | `wt step prune`                                 |
| `⚑` symbols accumulate            | duplicate branch worktrees                   | consolidate; pick one worktree to keep           |
| `✘` conflict symbols appear       | mid-operation (rebase/merge/cherry-pick)     | resolve or abort the operation                   |
| CI column blank on PR branches     | missing `gh`/`glab` CLI or authentication  | install CLI; verify `wt list --full` CI column  |
| `wt switch` fails with path busy  | stale directory at target path               | `--clobber` or manual delete                    |
| `wt merge` fails with hook error  | hook command non-zero exit                   | check hook; use `--no-hooks` to bypass          |
| cold start takes minutes           | no copy-ignored hook configured              | add `[post-start] copy = "wt step copy-ignored"` |

## Quick reference: core commands

| Command                        | What it does                                     |
| ------------------------------ | ------------------------------------------------ |
| `wt switch feat`               | Switch to existing worktree for branch `feat`     |
| `wt switch --create feat`      | Create branch `feat` and worktree, then switch    |
| `wt switch -`                  | Switch to previous worktree                      |
| `wt switch ^`                  | Switch to default branch                         |
| `wt list`                      | Human-readable worktree table                    |
| `wt list --full`               | Add CI, diff stats, LLM summaries                |
| `wt list --format=json`        | JSON output for scripts                          |
| `wt remove feat`               | Remove worktree; delete branch if merged         |
| `wt remove feat -D`            | Remove worktree and delete branch (unmerged)     |
| `wt merge`                     | Merge current into default; squash, rebase, clean|
| `wt merge --no-remove`         | Merge but keep worktree                          |
| `wt step diff`                 | Show all changes since branching                 |
| `wt step commit`               | Stage and generate LLM commit message            |
| `wt step squash`               | Squash commits; LLM message                      |
| `wt step prune --dry-run`      | Preview removable merged worktrees               |
| `wt step prune`                | Remove all merged worktrees                      |
| `wt step copy-ignored`         | Copy caches/deps to current worktree             |
| `wt step for-each -- <cmd>`    | Run command in every worktree                    |
| `wt config shell install`      | Install shell integration (one time)             |
| `wt config state vars set k=v` | Set per-branch variable                          |
