## Installation & Quarantine Fix

Install AeroSpace via Homebrew Cask (preferred) or from the GitHub Releases archive — [001-guide.md](aerospace-raw/001-guide.md).

```bash
# Preferred Homebrew installation (includes bash, fish, and zsh completions)
brew install --cask nikitabobko/tap/aerospace

# Pinned version example
brew install --cask nikitabobko/tap/aerospace@0.12.0
```

For manual installation, unpack the release zip, move `AeroSpace.app` to `/Applications`, and copy `bin/aerospace` into `$PATH`. Clear macOS Gatekeeper quarantine if blocked:

```bash
xattr -d com.apple.quarantine /Applications/AeroSpace.app
```

## Config Discovery & Fallbacks

AeroSpace searches two locations in TOML 1.1.0 format — [001-guide.md](aerospace-raw/001-guide.md):

1. `~/.aerospace.toml`
2. `${XDG_CONFIG_HOME}/aerospace/aerospace.toml` (defaults to `~/.config/aerospace/aerospace.toml`)

Presence of both files triggers an ambiguity error. Bootstrap a config from the app bundle:

```bash
cp /Applications/AeroSpace.app/Contents/Resources/default-config.toml ~/.aerospace.toml
```

### Fallback Rule

Scalar keys fall back to [default-config.toml](aerospace-raw/config-examples/default-config.toml). Vector-like keys fall back to empty arrays or tables — [001-guide.md](aerospace-raw/001-guide.md):

- `mode.*.binding` falls back to `{}` (your config must declare all modes and bindings).
- `on-focused-monitor-changed` falls back to `[]`.
- `exec` falls back to `inherit-env-vars = true` and `PATH = '/opt/homebrew/bin:/opt/homebrew/sbin:${PATH}'`.
- `persistent-workspaces` falls back to `[]` when `config-version = 2`.

## `config-version`

Omitting `config-version` selects `1` and emits a warning on `reload-config` — [001-guide.md](aerospace-raw/001-guide.md). Set `config-version = 2` to enable explicit `persistent-workspaces` and remove binding-inferred phantom workspaces.

### Per-Monitor Gaps Syntax

Gaps accept a constant integer or an array of monitor-pattern maps with a trailing fallback integer — [default-config.toml](aerospace-raw/config-examples/default-config.toml):

```toml
gaps.outer.top = [{ monitor.main = 16 }, { monitor."dell" = 32 }, 24]
```

### `exec` Environment Table

GUI apps on macOS lack Homebrew paths by default — [001-guide.md](aerospace-raw/001-guide.md). AeroSpace injects Homebrew into `PATH` unless you override `[exec]`:

```toml
[exec]
    inherit-env-vars = true
[exec.env-vars]
    PATH = '/opt/homebrew/bin:/opt/homebrew/sbin:${PATH}'
```

Inspect the resolved `exec-*` environment with `aerospace list-exec-env-vars`.

## Key Mapping & Supported Keys

Bindings default to `qwerty` physical key codes — [001-guide.md](aerospace-raw/001-guide.md). Switch layouts or add custom aliases under `key-mapping`:

```toml
key-mapping.preset = 'qwerty' # 'qwerty' | 'dvorak' | 'colemak'
key-mapping.key-notation-to-key-code = { unicorn = 'u' }
```

- **Modifiers:** `cmd`, `alt`, `ctrl`, `shift`.
- **Letters & Digits:** `a`–`z`, `0`–`9`, `keypad0`–`keypad9`, `f1`–`f20`, `left`, `down`, `up`, `right`.
- **Punctuation keys:** `minus`, `equal`, `period`, `comma`, `slash`, `backslash`, `quote`, `semicolon`, `backtick`, `leftSquareBracket`, `rightSquareBracket`, `sectionSign` (ISO).
- **Navigation & editing keys:** `space`, `enter`, `esc`, `backspace`, `tab`, `pageUp`, `pageDown`, `home`, `end`, `forwardDelete`.
- **Keypad keys:** `keypadClear`, `keypadDecimalMark`, `keypadDivide`, `keypadEnter`, `keypadEqual`, `keypadMinus`, `keypadMultiply`, `keypadPlus` — [default-config.toml](aerospace-raw/config-examples/default-config.toml).

## Binding Modes & AeroSpace Shell Syntax

AeroSpace starts in `main` mode (`[mode.main.binding]`). Custom modes deactivate all other mode bindings until `mode <name>` returns — [001-guide.md](aerospace-raw/001-guide.md).

```toml
[mode.main.binding]
    alt-shift-1 = 'move-node-to-workspace 1; workspace 1'
    alt-right = 'list-workspaces --monitor focused --empty no | workspace --stdin next'
    alt-shift-semicolon = 'mode service'

[mode.service.binding]
    esc = ['reload-config', 'mode main']
    r = ['flatten-workspace-tree', 'mode main']
```

### Shell Operators in Bindings & `eval`

AeroSpace implements `;`, `||`, `&&`, `|`, and `(...)` in descending precedence — [001-guide.md](aerospace-raw/001-guide.md):

- `&&` binds tighter than `||`: `foo || bar && baz` parses as `foo || (bar && baz)`.
- Pipe `|` matches `set -o pipefail` semantics.
- Array values (`['cmd1', 'cmd2']`) run commands sequentially.

## Common Pitfalls & Verification

- **Ambiguous config:** Delete either `~/.aerospace.toml` or `~/.config/aerospace/aerospace.toml` if AeroSpace reports two configs — [001-guide.md](aerospace-raw/001-guide.md).
- **Key interception conflicts:** Global hotkey tools (`skhd`, Karabiner-Elements, Raycast) can intercept keys before AeroSpace sees them — [001-guide.md](aerospace-raw/001-guide.md).
- **Verify config without GUI popups:** Run `aerospace config --config-path` and `aerospace reload-config --dry-run --no-gui` — [002-commands.md](aerospace-raw/002-commands.md).
