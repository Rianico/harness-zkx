## Global & Shared Options

Top-level invocation (`aerospace --help`): `aerospace [-h|--help] [-v|--version] <subcommand> [<args>...]` — see subcommands in [002-commands.md](aerospace-raw/002-commands.md).

| Flag | Scope | Description |
| --- | --- | --- |
| `-h`, `--help` | Top-level & every subcommand | Prints usage help and exits — [002-commands.md](aerospace-raw/002-commands.md) |
| `-v`, `--version` | Top-level | Prints CLI and server version and git hash |
| `--window-id <id>` | Window commands | Overrides target window (`AEROSPACE_WINDOW_ID` and focus) — [001-guide.md](aerospace-raw/001-guide.md) |
| `--workspace <name>` | Workspace commands | Overrides target workspace (`AEROSPACE_WORKSPACE` and focus) — [001-guide.md](aerospace-raw/001-guide.md) |
| `--fail-if-noop` | State-toggle commands | Exits non-zero when target is already in requested state — [002-commands.md](aerospace-raw/002-commands.md) |

Target resolution priority: `--window-id` > `--workspace` > `AEROSPACE_WINDOW_ID` > `AEROSPACE_WORKSPACE` > focused element — [001-guide.md](aerospace-raw/001-guide.md).

### Interpolation Variables (`--format`, `echo`, `test`)

All formatting commands share `%{right-padding}`, `%{newline}`, and `%{tab}` — [002-commands.md](aerospace-raw/002-commands.md):

- **Window vars (`list-windows`, `echo`, `test`):** `%{window-id}`, `%{window-title}`, `%{window-is-fullscreen}`, `%{window-layout}`, `%{window-parent-container-layout}`.
- **App vars (`list-windows`, `list-apps`, `echo`, `test`):** `%{app-bundle-id}`, `%{app-name}`, `%{app-pid}`, `%{app-exec-path}`, `%{app-bundle-path}`.
- **Workspace & Monitor vars:** `%{workspace}`, `%{workspace-is-focused}`, `%{workspace-is-visible}`, `%{workspace-root-container-layout}`, `%{monitor-id}`, `%{monitor-appkit-nsscreen-screens-id}`, `%{monitor-name}`, `%{monitor-is-main}`.
