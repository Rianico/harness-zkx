## `on-window-detected` Callbacks

`on-window-detected` is an ordered array of callback objects evaluated whenever a new window appears — [001-guide.md](aerospace-raw/001-guide.md).

```toml
on-window-detected = [
    {
        if = 'test %{app-bundle-id} = com.apple.systempreferences',
        check-further-callbacks = true,
        run = ['layout floating', 'move-node-to-workspace S'],
    },
    {
        if = 'test %{app-bundle-id} = com.google.Chrome || test %{app-bundle-id} = org.mozilla.firefox',
        run = 'move-node-to-workspace W',
    },
]
```

- **`if` (optional):** Command evaluated for exit status (`test`, `test-not`, `true`, `false`, or `||`/`&&` expressions). Exit `0` runs `run`.
- **`run` (required):** Command string or array run when `if` succeeds (or unconditionally if `if` is omitted).
- **`check-further-callbacks` (optional):** Defaults to `false`. Set `true` to continue matching later rules after a match.
- **Retroactive execution (`v0.21+`):** Run `aerospace run-callback --for-every-window on-window-detected` after `reload-config` — [002-commands.md](aerospace-raw/002-commands.md).
- **Title caveat:** Windows that populate titles after creation may miss `window-title-regex-substring` checks — [001-guide.md](aerospace-raw/001-guide.md).

### Legacy `if.*` Syntax (Soft-Deprecated)

The older `if.*` table syntax (for example `if.app-id`) remains supported but soft-deprecated in favor of `if = 'test %{...} = ...'` — [001-guide.md](aerospace-raw/001-guide.md).

Find bundle IDs via `aerospace list-apps`, [003-goodies.md](aerospace-raw/003-goodies.md), or `mdls -name kMDItemCFBundleIdentifier -r /Applications/App.app`.

## Focus & Workspace Change Callbacks

- **`on-focus-changed`:** Fires when focused window or workspace changes — [001-guide.md](aerospace-raw/001-guide.md).
- **`on-focused-monitor-changed`:** Fires when focused monitor changes — [001-guide.md](aerospace-raw/001-guide.md).
- **`exec-on-workspace-change`:** Runs an argv array as a subprocess on workspace switch with `AEROSPACE_FOCUSED_WORKSPACE` and `AEROSPACE_PREV_WORKSPACE` set — [001-guide.md](aerospace-raw/001-guide.md).

Focus callbacks are recursion-resistant so inner focus changes do not retrigger the callback — [001-guide.md](aerospace-raw/001-guide.md).

```toml
on-focused-monitor-changed = ['move-mouse monitor-lazy-center']
exec-on-workspace-change = ['/bin/bash', '-c',
    'sketchybar --trigger aerospace_workspace_change FOCUSED=$AEROSPACE_FOCUSED_WORKSPACE'
]
```

Note: [001-guide.md](aerospace-raw/001-guide.md) passes `FOCUSED=$AEROSPACE_FOCUSED_WORKSPACE` whereas [003-goodies.md](aerospace-raw/003-goodies.md) passes `FOCUSED_WORKSPACE=$AEROSPACE_FOCUSED_WORKSPACE`.

## Context Forwarding & Target Precedence

Callbacks forward either `AEROSPACE_WINDOW_ID` or `AEROSPACE_WORKSPACE` (never both simultaneously) to every command and child shell — [001-guide.md](aerospace-raw/001-guide.md):

1. `--window-id <id>` (highest priority)
2. `--workspace <name>`
3. `AEROSPACE_WINDOW_ID`
4. `AEROSPACE_WORKSPACE`
5. Currently focused window or empty workspace

This lets `move-node-to-workspace 2; layout floating` target the original window even after step 1 changes focus — [001-guide.md](aerospace-raw/001-guide.md).

## Event Streaming (`subscribe`)

`aerospace subscribe [--all] [--no-send-initial] [<event>...]` streams newline-delimited JSON events (`v0.21+`) — [002-commands.md](aerospace-raw/002-commands.md):

- Emits current state immediately on connect (`focus-changed`, `mode-changed`, etc.) and stays open until terminated (`Ctrl+C`) — [002-commands.md](aerospace-raw/002-commands.md).
- CLI usage lists `--all` and `--no-send-initial`, though upstream leaves their flag descriptions undocumented — [002-commands.md](aerospace-raw/002-commands.md).

| Event | Payload Fields |
| --- | --- |
| `focus-changed` | `windowId`, `workspace` |
| `focused-monitor-changed` | `workspace`, `monitorId` |
| `focused-workspace-changed` | `workspace`, `prevWorkspace` |
| `mode-changed` | `mode` |
| `window-detected` | `windowId`, `workspace`, `appBundleId`, `appName` |
| `binding-triggered` | `binding`, `mode` |

## Unix Domain Socket Protocol

Custom bars and editor plugins talk directly to `AeroSpace.app` over a Unix-domain stream socket — [001-guide.md](aerospace-raw/001-guide.md):

```bash
/tmp/bobko.aerospace-${USER}.sock        # Release build
/tmp/bobko.aerospace.debug-${USER}.sock  # Debug build
```

1. **Handshake:** Client sends `SOCKET_PROTOCOL_VERSION` (`1`) as a 4-byte unsigned integer in host byte order (little-endian on macOS). Server replies with its version (`1`) and closes on mismatch.
2. **Framing:** Each frame is a 4-byte `UInt32` LE payload length followed by UTF-8 JSON bytes.
3. **One-shot loop:** Client sends `ClientRequest` (`args`, `stdin`, `windowId`, `workspace`). Server replies with `ServerAnswer` (`exitCode`, `stdout`, `stderr`, `serverVersionAndHash`).
4. **Subscribe stream:** Send `args: ["subscribe", ...]` once, then read unbounded event frames until disconnect.

```python
import getpass, json, socket, struct

sock_path = f"/tmp/bobko.aerospace-{getpass.getuser()}.sock"

def recv_exact(s: socket.socket, n: int) -> bytes:
    buf = b""
    while len(buf) < n:
        chunk = s.recv(n - len(buf))
        if not chunk:
            raise ConnectionError("server closed connection")
        buf += chunk
    return buf

with socket.socket(socket.AF_UNIX, socket.SOCK_STREAM) as s:
    s.connect(sock_path)
    s.sendall(struct.pack("<I", 1))
    (ver,) = struct.unpack("<I", recv_exact(s, 4))
    if ver != 1:
        raise RuntimeError(f"unsupported server version {ver}")
    payload = json.dumps({
        "args": ["list-workspaces", "--focused"],
        "stdin": "",
        "windowId": None,
        "workspace": None,
    }).encode("utf-8")
    s.sendall(struct.pack("<I", len(payload)) + payload)
    (length,) = struct.unpack("<I", recv_exact(s, 4))
    answer = json.loads(recv_exact(s, length))
    print(answer["stdout"])
```
