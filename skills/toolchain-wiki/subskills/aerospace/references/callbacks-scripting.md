## `on-window-detected` Callbacks

`on-window-detected` is an ordered array of callback objects evaluated whenever a new window appears — [001-guide.md](aerospace-raw/001-guide.md).

```toml
on-window-detected = [
    {
        if = 'test %{app-bundle-id} = com.apple.systempreferences',
        check-further-callbacks = true,
        run = ['layout floating', 'move-node-to-workspace S'],
    },
    {
        if = 'test %{app-bundle-id} = com.google.Chrome || test %{app-bundle-id} = org.mozilla.firefox',
        run = 'move-node-to-workspace W',
    },
]
```

- **`if` (optional):** Command evaluated for exit status (`test`, `test-not`, `true`, `false`, or `||`/`&&` expressions). Exit `0` runs `run`.
- **`run` (required):** Command string or array run when `if` succeeds (or unconditionally if `if` is omitted).
- **`check-further-callbacks` (optional):** Defaults to `false`. Set `true` to continue matching later rules after a match.
- **Retroactive execution (`v0.21+`):** Run `aerospace run-callback --for-every-window on-window-detected` after `reload-config` — [002-commands.md](aerospace-raw/002-commands.md).
- **Title caveat:** Windows that populate titles after creation may miss `window-title-regex-substring` checks — [001-guide.md](aerospace-raw/001-guide.md).

### Legacy `if.*` Syntax (Soft-Deprecated)

The older `if.*` table syntax (for example `if.app-id`) remains supported but soft-deprecated in favor of `if = 'test %{...} = ...'` — [001-guide.md](aerospace-raw/001-guide.md).

Find bundle IDs via `aerospace list-apps`, [003-goodies.md](aerospace-raw/003-goodies.md), or `mdls -name kMDItemCFBundleIdentifier -r /Applications/App.app`.

## Focus & Workspace Change Callbacks

- **`on-focus-changed`:** Fires when focused window or workspace changes — [001-guide.md](aerospace-raw/001-guide.md).
- **`on-focused-monitor-changed`:** Fires when focused monitor changes — [001-guide.md](aerospace-raw/001-guide.md).
- **`exec-on-workspace-change`:** Runs an argv array as a subprocess on workspace switch with `AEROSPACE_FOCUSED_WORKSPACE` and `AEROSPACE_PREV_WORKSPACE` set — [001-guide.md](aerospace-raw/001-guide.md).

Focus callbacks are recursion-resistant so inner focus changes do not retrigger the callback — [001-guide.md](aerospace-raw/001-guide.md).

```toml
on-focused-monitor-changed = ['move-mouse monitor-lazy-center']
exec-on-workspace-change = ['/bin/bash', '-c',
    'sketchybar --trigger aerospace_workspace_change FOCUSED=$AEROSPACE_FOCUSED_WORKSPACE'
]
```

Note: [001-guide.md](aerospace-raw/001-guide.md) passes `FOCUSED=$AEROSPACE_FOCUSED_WORKSPACE` whereas [003-goodies.md](aerospace-raw/003-goodies.md) passes `FOCUSED_WORKSPACE=$AEROSPACE_FOCUSED_WORKSPACE`.

## Context Forwarding & Target Precedence

Callbacks forward either `AEROSPACE_WINDOW_ID` or `AEROSPACE_WORKSPACE` (never both simultaneously) to every command and child shell — [001-guide.md](aerospace-raw/001-guide.md):

1. `--window-id <id>` (highest priority)
2. `--workspace <name>`
3. `AEROSPACE_WINDOW_ID`
4. `AEROSPACE_WORKSPACE`
5. Currently focused window or empty workspace

This lets `move-node-to-workspace 2; layout floating` target the original window even after step 1 changes focus — [001-guide.md](aerospace-raw/001-guide.md).

## Event Streaming (`subscribe`)

`aerospace subscribe` (`v0.21+`) connects to `AeroSpace.app` over its Unix socket and streams real-time state transitions as JSON Lines (JSONL) — [002-commands.md](aerospace-raw/002-commands.md):

### CLI Syntax & Flags

```bash
aerospace subscribe [--all] [--no-send-initial] [<event>...]
```

- **`--all`:** Subscribes to all 6 event types without listing each name explicitly.
- **`--no-send-initial`:** Suppresses the initial state snapshot on connect. By default, AeroSpace immediately emits the current state (`focused-monitor-changed`, `focused-workspace-changed`, `mode-changed`, `focus-changed`, etc.) when the stream opens.
- **`<event>...`:** One or more event names from the catalog below.
- **Stream lifetime:** The connection remains open until terminated by `Ctrl+C`, client disconnect, or an `AeroSpace.app` restart or upgrade.

### Event Catalog & Wire Schema (`v0.21.3-Beta`)

Verified against AeroSpace `v0.21.3-Beta` (`ServerEvent.swift` / `aerospace-subscribe(1)`). Every emitted JSON object includes `_event` plus the event-specific wire fields:

| Event | Wire Fields | Notes |
| --- | --- | --- |
| `focused-workspace-changed` | `_event`, `workspace`, `prevWorkspace` | Fires when workspace focus moves between workspaces |
| `focused-monitor-changed` | `_event`, `monitorId`, `workspace` | `monitorId` is AeroSpace's 1-based geometric `(rect.minX, rect.minY)` ID, **not** SketchyBar's `arrangement-id` or AppKit's `NSScreen.screens` index; see [goodies-integrations.md](goodies-integrations.md) for deterministic mapping |
| `focus-changed` | `_event`, `windowId`, `workspace` | `windowId` is omitted when focusing an empty workspace |
| `mode-changed` | `_event`, `mode` | Fires when the active keybinding mode changes |
| `window-detected` | `_event`, `windowId`, `workspace`, `appBundleId`, `appName` | Fires when AeroSpace detects a new window |
| `binding-triggered` | `_event`, `binding`, `mode` | Fires when an AeroSpace keybinding executes |

Concrete JSONL wire examples:

```json
{"_event":"focused-monitor-changed","monitorId":1,"workspace":"M"}
{"_event":"focused-workspace-changed","prevWorkspace":"M","workspace":"1"}
{"_event":"mode-changed","mode":"main"}
{"_event":"focus-changed","windowId":28218,"workspace":"1"}
```

### Socket-Level Subscribe Streaming

Direct socket clients can subscribe without spawning the CLI binary:

1. Connect to `/tmp/bobko.aerospace-${USER}.sock` and complete the 4-byte LE `SOCKET_PROTOCOL_VERSION` (`1`) handshake (see [Unix Domain Socket Protocol](#unix-domain-socket-protocol)).
2. Send one `ClientRequest` frame with `args: ["subscribe", ...]` (for example `["subscribe", "--all"]` or `["subscribe", "--no-send-initial", "focused-workspace-changed"]`).
3. Read unbounded 4-byte LE length-prefixed `ServerEvent` JSON frames in a loop until the client closes the socket or `AeroSpace.app` restarts/exits.

### Known Event Coverage Gaps (`v0.21.3-Beta`) & Workarounds

AeroSpace `v0.21.3-Beta` emits **no dedicated event** for `window-moved-to-workspace`, `window-closed`, or `workspace-moved-to-monitor`. Choose one of two practical workarounds:

1. **Observe `binding-triggered` + `focus-changed`:** Watch `binding-triggered` for move keybindings (or a dedicated move/send mode) alongside `focus-changed` (which fires when a window closes or moves away and focus shifts) to trigger targeted workspace refreshes.
2. **Hybrid hooks for move bindings only:** Keep explicit `sketchybar --trigger` (or bar IPC) hooks solely on `move-node-to-workspace` and `move-workspace-to-monitor` bindings while migrating `focused-workspace-changed`, `focused-monitor-changed`, `mode-changed`, and `window-detected` onto `subscribe`.

### Consumer Daemon Hygiene

- **Reconnect across restarts:** Wrap `aerospace subscribe` in a `while true` loop so an `AeroSpace.app` restart or upgrade cleanly re-establishes the stream:

```bash
while true; do
  aerospace subscribe focused-workspace-changed focused-monitor-changed mode-changed window-detected \
    | while IFS= read -r event; do
        # parse JSONL and batch bar updates
        :
      done
  sleep 1
done
```

- **Deduplicate on bar reload:** Guard startup with a pidfile (or `pkill -f`) so `sketchybar --reload` does not accumulate orphan listener processes:

```bash
PIDFILE="${TMPDIR:-/tmp}/aerospace-bar-bridge.pid"
[ -f "$PIDFILE" ] && kill "$(cat "$PIDFILE")" 2>/dev/null || true
echo $$ > "$PIDFILE"
trap 'rm -f "$PIDFILE"' EXIT
```

- **Batch bar updates:** Dispatch all item updates directly inside the persistent listener instead of spawning `/bin/bash -c` subprocesses via `exec-on-workspace-change` on every switch.

## Unix Domain Socket Protocol

Custom bars and editor plugins talk directly to `AeroSpace.app` over a Unix-domain stream socket — [001-guide.md](aerospace-raw/001-guide.md):

```bash
/tmp/bobko.aerospace-${USER}.sock        # Release build
/tmp/bobko.aerospace.debug-${USER}.sock  # Debug build
```

1. **Handshake:** Client sends `SOCKET_PROTOCOL_VERSION` (`1`) as a 4-byte unsigned integer in host byte order (little-endian on macOS). Server replies with its version (`1`) and closes on mismatch.
2. **Framing:** Each frame is a 4-byte `UInt32` LE payload length followed by UTF-8 JSON bytes.
3. **One-shot loop:** Client sends `ClientRequest` (`args`, `stdin`, `windowId`, `workspace`). Server replies with `ServerAnswer` (`exitCode`, `stdout`, `stderr`, `serverVersionAndHash`).
4. **Subscribe stream:** Send `args: ["subscribe", ...]` once, then read unbounded event frames until disconnect.

```python
import getpass, json, socket, struct

sock_path = f"/tmp/bobko.aerospace-{getpass.getuser()}.sock"

def recv_exact(s: socket.socket, n: int) -> bytes:
    buf = b""
    while len(buf) < n:
        chunk = s.recv(n - len(buf))
        if not chunk:
            raise ConnectionError("server closed connection")
        buf += chunk
    return buf

with socket.socket(socket.AF_UNIX, socket.SOCK_STREAM) as s:
    s.connect(sock_path)
    s.sendall(struct.pack("<I", 1))
    (ver,) = struct.unpack("<I", recv_exact(s, 4))
    if ver != 1:
        raise RuntimeError(f"unsupported server version {ver}")
    payload = json.dumps({
        "args": ["list-workspaces", "--focused"],
        "stdin": "",
        "windowId": None,
        "workspace": None,
    }).encode("utf-8")
    s.sendall(struct.pack("<I", len(payload)) + payload)
    (length,) = struct.unpack("<I", recv_exact(s, 4))
    answer = json.loads(recv_exact(s, length))
    print(answer["stdout"])
```
