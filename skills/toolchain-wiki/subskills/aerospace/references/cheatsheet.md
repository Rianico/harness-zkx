## Decision Rules

| When you need to | Do this | Because |
| --- | --- | --- |
| Validate config without popups | `aerospace reload-config --dry-run --no-gui` | Reports TOML errors on stdout and exits non-zero — [002-commands.md](aerospace-raw/002-commands.md) |
| Combine two windows into a split | `join-with (left\|down\|up\|right)` | Works with container flattening enabled — [002-commands.md](aerospace-raw/002-commands.md) |
| Float or move new windows | `on-window-detected = [...]` with `if = 'test %{app-bundle-id} = ...'` | `if.*` syntax is soft-deprecated — [001-guide.md](aerospace-raw/001-guide.md) |
| Apply new window rules now | `aerospace run-callback --for-every-window on-window-detected` | Re-runs rules against existing windows (`v0.21+`) — [002-commands.md](aerospace-raw/002-commands.md) |
| Target a specific window in script | Pass `--window-id <id>` or `--workspace <name>` | Overrides `AEROSPACE_WINDOW_ID` and focus — [001-guide.md](aerospace-raw/001-guide.md) |
| Keep empty workspaces visible | Set `config-version = 2` and `persistent-workspaces = [...]` | `v2` disables binding-inferred workspaces — [001-guide.md](aerospace-raw/001-guide.md) |
| Fix leaked hidden windows | Ensure free bottom-left/right corners in Displays Arrange | AeroSpace hides inactive windows in bottom corners — [001-guide.md](aerospace-raw/001-guide.md) |
| Open new Safari/Terminal window | Bind `exec-and-forget osascript ...` | `open -a` jumps to existing app workspace — [003-goodies.md](aerospace-raw/003-goodies.md) |

## Essential `~/.aerospace.toml` Snippet

```toml
config-version = 2
on-focused-monitor-changed = ['move-mouse monitor-lazy-center']

on-window-detected = [
    { if = 'test %{app-bundle-id} = com.apple.systempreferences', run = 'layout floating' },
]

[mode.main.binding]
    alt-h = 'focus left'
    alt-j = 'focus down'
    alt-k = 'focus up'
    alt-l = 'focus right'
    alt-shift-1 = 'move-node-to-workspace 1; workspace 1'
```

## macOS Prerequisite Checklist

1. Grant Accessibility permission to `AeroSpace.app`.
2. Leave free space in bottom-left or bottom-right monitor corners (`System Settings -> Displays -> Arrange...`).
3. Enable `defaults write com.apple.dock expose-group-apps -bool true && killall Dock` for Mission Control clarity.
4. Optionally disable `Displays have separate Spaces` (`defaults write com.apple.spaces spans-displays -bool true && killall SystemUIServer`, logout required).
