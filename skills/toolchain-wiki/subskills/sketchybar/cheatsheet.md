## Decision Rules

| When you need to | Do this | Because |
| :--- | :--- | :--- |
| apply shared item styling | call `sketchybar --default "${default[@]}"` first | subsequent items inherit active defaults |
| group items in one pill | `--add bracket name '/pattern.*/'` | bracket draws one shared background |
| mirror a macOS menu icon | `--add alias "Owner,Item" right` | captures native widget without writing plugin |
| react to system changes | `--subscribe item event` | avoids polling CPU overhead |
| animate color or offset | `--animate sin 15 --set item ...` | interpolates integer and ARGB properties |
| toggle a dropdown menu | `click_script="sketchybar --set \$NAME popup.drawing=toggle"` | shows items placed at `popup.<item>` |
| update items by pattern | `--set '/space\..*/' prop=val` | slash-delimited regex matches multiple items |
| avoid infinite script loops | run `sketchybar --update` only at end of `sketchybarrc` | calling `--update` inside plugins recurses |

## CLI Quick Lookup

| Task | Command | Notes |
| :--- | :--- | :--- |
| Configure bar | `sketchybar --bar position=top height=32` | Global bar appearance |
| Set defaults | `sketchybar --default "${default[@]}"` | Applies to later items |
| Add item | `sketchybar --add item name left` | Positions: `left`, `right`, `center`, `q`, `e` |
| Add component | `sketchybar --add space\|bracket\|alias\|slider\|graph ...` | Specialized item kinds |
| Update item | `sketchybar --set name icon=X label=Y` | Supports `/<regex>/` target |
| Subscribe event | `sketchybar --subscribe name front_app_switched` | Runs `script` on event |
| Custom event | `sketchybar --add event name [NSDistributedNotification]` | Trigger via `--trigger name K=V` |
| Animate change | `sketchybar --animate tanh 20 --set name ...` | Duration in 60Hz frames |
| Query state | `sketchybar --query bar\|defaults\|displays\|events\|name` | Outputs JSON |
| Reload config | `sketchybar --reload [path]` or `--hotload on` | Re-reads `sketchybarrc` |

## Events and Environment Matrix

| Event | `$SENDER` | `$INFO` / Extra Env |
| :--- | :--- | :--- |
| Routine timer (`update_freq`) | `routine` | None |
| `front_app_switched` | `front_app_switched` | `$INFO` = app name |
| `space_change` | `space_change` | `$INFO` = spaces JSON (`space` gets `$SELECTED`, `$SID`, `$DID`) |
| `volume_change` / `brightness_change` | event name | `$INFO` = integer percent |
| `power_source_change` | `power_source_change` | `$INFO` = `AC` or `BATTERY` |
| `mouse.clicked` | `mouse.clicked` | `$BUTTON`, `$MODIFIER` (`slider` gets `$PERCENTAGE`) |
| `mouse.scrolled` | `mouse.scrolled` | `$SCROLL_DELTA` |

All scripts receive `$NAME`, `$SENDER`, `$CONFIG_DIR`, and `$BAR_NAME`.

## Starter `sketchybarrc` Skeleton

```bash
#!/bin/bash
PLUGIN_DIR="$CONFIG_DIR/plugins"

sketchybar --bar position=top height=36 blur_radius=30 color=0x40000000

default=(
  padding_left=5
  padding_right=5
  icon.font="Hack Nerd Font:Bold:17.0"
  label.font="Hack Nerd Font:Bold:14.0"
  icon.color=0xffffffff
  label.color=0xffffffff
)
sketchybar --default "${default[@]}"

sketchybar --add item front_app left \
           --set front_app icon.drawing=off script="$PLUGIN_DIR/front_app.sh" \
           --subscribe front_app front_app_switched

sketchybar --update
```
