## Event-Driven Scripting Model

Items execute scripts via `update_freq` polling, `--subscribe` event bindings, or `click_script` ([Events.md](sketchybar-raw/docs/config/Events.md)).
Subscribing to events beats polling because scripts run only on state transitions ([Events.md](sketchybar-raw/docs/config/Events.md)).
SketchyBar terminates any plugin script after 60 seconds and pauses script execution while the Mac sleeps ([Events.md](sketchybar-raw/docs/config/Events.md)).

```bash
sketchybar --subscribe <name> <event> ... <event>
```

## Built-In Events

| Event | Trigger Condition | `$INFO` Payload |
| :--- | :--- | :--- |
| `front_app_switched` | Active application changes | Front application name |
| `space_change` | Active Mission Control space changes | JSON map of active spaces per display |
| `space_windows_change` | Window created or destroyed on a space | JSON with space and app windows |
| `display_change` | Active display changes | New active display ID |
| `volume_change` | System audio volume changes | New volume percentage |
| `brightness_change` | Display brightness changes | New brightness percentage |
| `power_source_change` | Power source switches | `AC` or `BATTERY` |
| `wifi_change` | Wi-Fi connects or disconnects | SSID or empty (broken since macOS Sonoma) |
| `media_change` | Now-playing media changes (deprecated on macOS 26.0) | JSON media metadata |
| `system_will_sleep` | System prepares to sleep | Empty |
| `system_woke` | System wakes from sleep | Empty |
| `mouse.entered` | Pointer enters item bounds | Empty |
| `mouse.exited` | Pointer leaves item bounds | Empty |
| `mouse.entered.global` | Pointer enters anywhere on the bar | Empty |
| `mouse.exited.global` | Pointer leaves the bar | Empty |
| `mouse.clicked` | Item is clicked | Mouse button and modifier details |
| `mouse.scrolled` | Mouse scrolls over item | Scroll wheel delta |
| `mouse.scrolled.global` | Mouse scrolls over empty bar space | Scroll wheel delta |

Source: [Events.md](sketchybar-raw/docs/config/Events.md).

## Script Environment Variables

| Variable | Availability | Value |
| :--- | :--- | :--- |
| `$NAME` | All scripts | Invoking item name |
| `$SENDER` | All scripts | Event name, or `routine` for `update_freq` |
| `$INFO` | Event-specific | Event payload string or JSON |
| `$CONFIG_DIR` | All scripts | Absolute directory of active `sketchybarrc` |
| `$BAR_NAME` | All scripts | Name of invoking SketchyBar instance |
| `$BUTTON` | Click events | `left`, `right`, `middle`, or `other` |
| `$MODIFIER` | Click events | `shift`, `ctrl`, `alt`, or `cmd` |
| `$SCROLL_DELTA` | Scroll events | Scroll delta value |
| `$SELECTED` / `$SID` / `$DID` | `space` components | Active boolean, space ID, display ID |
| `$PERCENTAGE` | `slider` clicks | Clicked slider percentage (`0` to `100`) |

Source: [Events.md](sketchybar-raw/docs/config/Events.md), [Components.md](sketchybar-raw/docs/config/Components.md).

## Custom Events and Initialization

```bash
# Register a custom event (optionally bound to NSDistributedNotificationCenter)
sketchybar --add event lock_screen "com.apple.screenIsUnlocked"
sketchybar --add event custom_deploy

# Trigger manually with optional environment variables
sketchybar --trigger custom_deploy ENV_STATUS=ready

# Force initial script run once at the end of sketchybarrc
sketchybar --update
```

Do not call `sketchybar --update` inside a plugin script because it causes an infinite loop ([Events.md](sketchybar-raw/docs/config/Events.md)).

## Official Starter Plugin Patterns

Every plugin file must be executable (`chmod +x plugin.sh`) ([setup.md](sketchybar-raw/docs/setup.md)).

### Event-Only Handler (`front_app.sh`)

```sh
#!/bin/sh
if [ "$SENDER" = "front_app_switched" ]; then
  sketchybar --set "$NAME" label="$INFO"
fi
```

### Volume Icon Switch (`volume.sh`)

```sh
#!/bin/sh
if [ "$SENDER" = "volume_change" ]; then
  VOLUME="$INFO"
  case "$VOLUME" in
    [6-9][0-9]|100) ICON="󰕾" ;;
    [3-5][0-9]) ICON="󰖀" ;;
    [1-9]|[1-2][0-9]) ICON="󰕿" ;;
    *) ICON="󰖁" ;;
  esac
  sketchybar --set "$NAME" icon="$ICON" label="$VOLUME%"
fi
```

### Routine Polling (`clock.sh` & `battery.sh`)

```sh
#!/bin/sh
sketchybar --set "$NAME" label="$(date '+%d/%m %H:%M')"
```

```sh
#!/bin/sh
PERCENTAGE="$(pmset -g batt | grep -Eo "\d+%" | cut -d% -f1)"
CHARGING="$(pmset -g batt | grep 'AC Power')"
[ "$PERCENTAGE" = "" ] && exit 0
case "${PERCENTAGE}" in
  9[0-9]|100) ICON="" ;;
  [6-8][0-9]) ICON="" ;;
  [3-5][0-9]) ICON="" ;;
  [1-2][0-9]) ICON="" ;;
  *) ICON="" ;;
esac
if [ "$CHARGING" != "" ]; then
  ICON=""
fi
sketchybar --set "$NAME" icon="$ICON" label="${PERCENTAGE}%"
```

### Common Pitfalls

- [Events.md](sketchybar-raw/docs/config/Events.md): Running `sketchybar --update` inside a plugin triggers every script recursively.
- [Events.md](sketchybar-raw/docs/config/Events.md): `wifi_change` does not work since macOS Sonoma.
- [setup.md](sketchybar-raw/docs/setup.md): Non-executable plugin files fail silently unless `sketchybar` is inspected in foreground mode.
