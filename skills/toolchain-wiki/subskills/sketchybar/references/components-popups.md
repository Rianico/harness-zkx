## Component Overview

Components extend standard items with specialized rendering and state behavior ([Components.md](sketchybar-raw/docs/config/Components.md)).
Components inherit standard item properties except `bracket`, which supports only `background.*` properties ([Components.md](sketchybar-raw/docs/config/Components.md)).

## Component: `space` (Mission Control Spaces)

- **Library/Package:** sketchybar
- **Language/Shell:** Bash / Zsh

### Syntax

```bash
sketchybar --add space <name> <position>
sketchybar --set <name> space=<space_id> [display=<display_id>] [script=<path>]
```

### Description

Associates an item with a Mission Control space ([Components.md](sketchybar-raw/docs/config/Components.md)).
The `space` property must be set to bind the item to its space ID ([Components.md](sketchybar-raw/docs/config/Components.md)).
By default, `space` executes `sketchybar --set $NAME icon.highlight=$SELECTED` only when `$SELECTED` changes ([Components.md](sketchybar-raw/docs/config/Components.md)).

### Environment Variables

- `$SELECTED`: `true` when space is active, otherwise `false`
- `$SID`: Mission Control space ID
- `$DID`: Display ID hosting the space

### Practical Examples

```bash
SPACE_ICONS=("1" "2" "3" "4" "5")
for i in "${!SPACE_ICONS[@]}"; do
  sid="$((i + 1))"
  sketchybar --add space space."$sid" left \
             --set space."$sid" space="$sid" icon="${SPACE_ICONS[i]}" \
                   label.drawing=off script="$CONFIG_DIR/plugins/space.sh" \
                   click_script="yabai -m space --focus $sid"
done
```

## Component: `bracket` (Item Grouping)

```bash
sketchybar --add bracket <name> <member_or_regex> ...
```

Draws a shared background behind multiple items, including regex targets like `'/space\..*/'` ([Components.md](sketchybar-raw/docs/config/Components.md)).
Brackets support **only** `background.*` properties (no `icon`, `label`, or scripts) and can span across bar regions such as `left` and `center` ([Components.md](sketchybar-raw/docs/config/Components.md)).

```bash
sketchybar --add bracket spaces '/space\..*/' \
           --set spaces background.color=0xffffffff \
                        background.corner_radius=4 \
                        background.height=20
```

## Component: `alias` (macOS Menu Bar Mirror)

```bash
sketchybar --add alias <application_name> <position>
sketchybar --add alias "<window_owner>,<window_name>" <position>
```

Mirrors native macOS menu bar widgets into SketchyBar even when the macOS menu bar autohides ([Components.md](sketchybar-raw/docs/config/Components.md)).
Requires **Screen Recording** permission in macOS System Settings ([Components.md](sketchybar-raw/docs/config/Components.md)).
Discover available owner/name pairs with `sketchybar --query default_menu_items` ([Components.md](sketchybar-raw/docs/config/Components.md)).

| Property | Type | Default | Description |
| :--- | :--- | :--- | :--- |
| `alias.color` | `<argb_hex>` | | Override mirrored icon color |
| `alias.scale` | `<float>` | | Scale factor of the mirrored icon |
| `alias.update_freq` | `<positive_integer>` | `1` | Refresh interval in seconds |

### Common Pitfalls

- [Tricks.md](sketchybar-raw/docs/config/Tricks.md): Avoid adding aliases for apps that are not always running because SketchyBar searches for them continuously.

## Component: `slider` (Draggable Progress Bar)

```bash
sketchybar --add slider <name> <position> <width>
```

| Property | Type | Default | Description |
| :--- | :--- | :--- | :--- |
| `slider.width` | `<positive_integer>` | `100` | Total slider width in points |
| `slider.percentage` | `<positive_integer>` | `0` | Progress value (`0` to `100`) |
| `slider.highlight_color` | `<argb_hex>` | `0xff0000ff` | Filled progress track color |
| `slider.knob` | `<string>` | | Knob glyph string |
| `slider.knob.<text_property>` | | | All text properties for the knob |
| `slider.background.<background_property>` | | | All background properties for the slider track |

Subscribe to `mouse.clicked` to receive `$PERCENTAGE` on click or drag release ([Components.md](sketchybar-raw/docs/config/Components.md)).


| Property | Type | Default | Description |
| :--- | :--- | :--- | :--- |
| `graph.color` | `<argb_hex>` | `0xffcccccc` | Graph stroke color |
| `graph.fill_color` | `<argb_hex>` | `0xffcccccc` | Graph area fill color |

## Component: `popup` Menus

Every bar item owns an attached popup menu ([Popup.md](sketchybar-raw/docs/config/Popup.md)).
Add child items to a popup using `popup.<parent_name>` as the `<position>` ([Popup.md](sketchybar-raw/docs/config/Popup.md)).

```bash
sketchybar --add item apple.logo left \
           --set apple.logo icon= popup.align=left \
                            click_script="sketchybar --set \$NAME popup.drawing=toggle" \
           --add item apple.prefs popup.apple.logo \
           --set apple.prefs label="Preferences" \
                             click_script="open -a 'System Settings'; sketchybar --set apple.logo popup.drawing=off"
```

| Popup Property | Type | Default | Description |
| :--- | :--- | :--- | :--- |
| `popup.drawing` | `<boolean>` | `off` | Show, hide, or `toggle` popup |
| `popup.horizontal` | `<boolean>` | `off` | Lay out popup items horizontally |
| `popup.topmost` | `<boolean>` | `on` | Keep popup above other windows |
| `popup.height` | `<positive_integer>` | bar height | Vertical spacing between popup items |
| `popup.blur_radius` | `<positive_integer>` | `0` | Popup background blur |
| `popup.y_offset` | `<integer>` | `0` | Vertical offset from bar |
| `popup.align` | `left`, `right`, `center` | `left` | Alignment relative to parent item |
| `popup.background.<prop>` | | | All background properties |
