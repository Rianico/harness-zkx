## Item Lifecycle Commands

- **Library/Package:** sketchybar
- **Language/Shell:** Bash / Zsh

### Syntax

```bash
sketchybar --add item <name> <position>
sketchybar --set <name> <property>=<value> ...
sketchybar --default <property>=<value> ...
sketchybar --clone <name> <parent_name> [before|after]
sketchybar --rename <old_name> <new_name>
sketchybar --move <name> <before|after> <reference_name>
sketchybar --reorder <name> ... <name>
sketchybar --remove <name>
```

### Description

- `<position>` places items at `left`, `right`, `center`, `q` (left of notch), or `e` (right of notch) ([Items.md](sketchybar-raw/docs/config/Items.md)).
- `--set` and `--remove` accept a regex wrapped in slashes, such as `/space\..*/` ([Items.md](sketchybar-raw/docs/config/Items.md)).
- `--default` sets inherited defaults for all items created after that point in `sketchybarrc` ([Items.md](sketchybar-raw/docs/config/Items.md)).
- `--clone` inherits all parent properties and optionally positions the clone `before` or `after` the parent ([Items.md](sketchybar-raw/docs/config/Items.md)).

### Practical Examples

```bash
# Set shared defaults before creating items
default=(
  padding_left=5
  padding_right=5
  icon.font="Hack Nerd Font:Bold:17.0"
  label.font="Hack Nerd Font:Bold:14.0"
  icon.color=0xffffffff
  label.color=0xffffffff
)
sketchybar --default "${default[@]}"

# Add left item, move, reorder, and regex-update
sketchybar --add item front_app left --set front_app icon.drawing=off
sketchybar --move front_app after chevron
sketchybar --reorder item_a item_b
sketchybar --set '/space\..*/' background.corner_radius=5
```

## Icon, Label, and Text Properties

Set icons and labels with `icon=<string>`, `label=<string>`, `icon.<text_property>=<value>`, or `label.<text_property>=<value>` ([Items.md](sketchybar-raw/docs/config/Items.md)).

| Text Property | Type | Default | Description |
| :--- | :--- | :--- | :--- |
| `drawing` | `<boolean>` | `on` | Render text |
| `highlight` | `<boolean>` | `off` | Switch between `color` and `highlight_color` |
| `color` | `<argb_hex>` | `0xffffffff` | Default text color |
| `highlight_color` | `<argb_hex>` | `0xff000000` | Highlight text color |
| `padding_left` / `padding_right` | `<integer>` | `0` | Horizontal text padding |
| `y_offset` | `<integer>` | `0` | Vertical text offset |
| `font` | `<family>:<type>:<size>` | `Hack Nerd Font:Bold:14.0` | Combined font spec |
| `font.family` / `font.style` / `font.size` | `<string>` / `<string>` / `<float>` | `Hack Nerd Font` / `Bold` / `14.0` | Individual font fields |
| `string` | `<string>` | | Text content |
| `max_chars` | `<positive_integer>` | `0` | Character limit before truncation |
| `scroll_duration` | `<positive_integer>` | `100` | Scroll speed when `scroll_texts=on` |
| `width` | `<positive_integer>`, `dynamic` | `dynamic` | Fixed text box width |
| `align` | `center`, `left`, `right` | `left` | Text alignment inside fixed `width` |
| `background.<prop>` / `shadow.<prop>` | | | Nested text background or shadow |

## Background, Image, and Shadow Properties

Apply `background.<prop>` to items, `icon`, `label`, `popup`, or `slider` ([Items.md](sketchybar-raw/docs/config/Items.md)).

| Background Property | Type | Default | Description |
| :--- | :--- | :--- | :--- |
| `drawing` | `<boolean>` | `off` | Draw background |
| `color` | `<argb_hex>` | `0x00000000` | Fill color |
| `border_color` | `<argb_hex>` | `0x00000000` | Border color |
| `border_width` | `<positive_integer>` | `0` | Border width |
| `height` | `<positive_integer>` | `0` | Background height override |
| `corner_radius` | `<positive_integer>` | `0` | Corner radius |
| `padding_left` / `padding_right` | `<integer>` | `0` | Horizontal background padding |
| `x_offset` / `y_offset` | `<integer>` | `0` | Background offset |
| `clip` | `<float>` | `0.0` | Clip amount cutting transparent holes in the bar |
| `image` | `<path>`, `app.<bundle-id>`, `app.<name>`, `media.artwork` | | Background image source |

Image sub-properties (`background.image.<prop>`): `drawing` (`off`), `scale` (`1.0`), `border_color` (`0x00000000`), `border_width` (`0`), `corner_radius` (`0`), `padding_left` (`0`), `padding_right` (`0`), `y_offset` (`0`), `string`, `shadow.<prop>` ([Items.md](sketchybar-raw/docs/config/Items.md)).

Shadow sub-properties (`shadow.<prop>`): `drawing` (`off`), `color` (`0xff000000`), `angle` (`30`), `distance` (`5`) ([Items.md](sketchybar-raw/docs/config/Items.md)).

## Type Nomenclature

| Type | Valid Values | Notes |
| :--- | :--- | :--- |
| `<boolean>` | `on`, `off`, `yes`, `no`, `true`, `false`, `1`, `0`, `toggle` | Negate any boolean with `!`, e.g. `!on` |
| `<argb_hex>` | `0xAARRGGBB` | Access channels individually via `.alpha`, `.red`, `.green`, `.blue` (`0` to `1` float) |
| `<path>` | Absolute file path | Required for plugin scripts and image files |
| `<string>` | UTF-8 string or symbol | Quote strings containing spaces |
| `<float>` / `<integer>` / `<positive_integer>` | Numeric scalars | Positive integer lists use comma separation |

Example channel mutation: `sketchybar --bar color.alpha=0.5` ([Types.md](sketchybar-raw/docs/config/Types.md)).

### Common Pitfalls

- [Items.md](sketchybar-raw/docs/config/Items.md): Item names containing spaces must be quoted, or avoid spaces completely.
- [Types.md](sketchybar-raw/docs/config/Types.md): Supplying 6-digit RGB hex instead of 8-digit ARGB (`0xAARRGGBB`) yields invisible `00` alpha.
