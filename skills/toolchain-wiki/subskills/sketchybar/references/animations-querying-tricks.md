## Command: `sketchybar --animate`

- **Library/Package:** sketchybar
- **Language/Shell:** Bash / Zsh

### Syntax

```bash
sketchybar --animate <curve> <duration_frames> \
           --bar <property>=<value> ... \
           --set <name> <property>=<value> ...
```

### Description

Animates transitions for `<argb_hex>`, `<integer>`, and `<positive_integer>` values ([Animations.md](sketchybar-raw/docs/config/Animations.md)).
`<duration_frames>` measures frames on a 60Hz display, so `30` frames equals `0.5` seconds ([Animations.md](sketchybar-raw/docs/config/Animations.md)).

### Supported Curves

| Curve | Behavior |
| :--- | :--- |
| `linear` | Constant velocity |
| `quadratic` | Quadratic ease |
| `tanh` | Hyperbolic tangent ease |
| `sin` | Sinusoidal ease |
| `exp` | Exponential ease |
| `circ` | Circular ease |

### Chaining and Cancellation

Repeat the same property in one `--animate` call to queue sequential keyframes ([Animations.md](sketchybar-raw/docs/config/Animations.md)):

```bash
sketchybar --animate sin 30 --bar y_offset=10 y_offset=0
```

Set a property to its current value in the first slot to delay its transition until the next keyframe ([Animations.md](sketchybar-raw/docs/config/Animations.md)).
A new non-animated `--set` cancels active animations immediately. A new `--animate` restarts from the current intermediate value ([Animations.md](sketchybar-raw/docs/config/Animations.md)).

## Command: `sketchybar --query`

```bash
sketchybar --query bar                  # Global bar configuration JSON
sketchybar --query <item_name>          # Item state and properties JSON
sketchybar --query defaults             # Current default item values JSON
sketchybar --query events               # Registered events JSON
sketchybar --query displays             # Current display configuration JSON
sketchybar --query default_menu_items   # Native macOS menu bar items for --add alias
```

Source: [Querying.md](sketchybar-raw/docs/config/Querying.md).

## Batching and Performance

### Batching Commands

Each separate `sketchybar` invocation can trigger a bar redraw ([Tricks.md](sketchybar-raw/docs/config/Tricks.md)).
Combine commands in one invocation using bash arrays or backslash line continuations ([Tricks.md](sketchybar-raw/docs/config/Tricks.md)):

```bash
bar=(
  height=32
  blur_radius=30
  position=top
  sticky=off
  padding_left=10
  padding_right=10
  color=0x15ffffff
)
sketchybar --bar "${bar[@]}"
```

Never leave trailing whitespace after a `\` continuation character because Bash stops parsing the command at that line ([Tricks.md](sketchybar-raw/docs/config/Tricks.md)).

### Performance Optimization Checklist

- Batch configuration and property updates into single `sketchybar` calls ([Tricks.md](sketchybar-raw/docs/config/Tricks.md)).
- Set `updates=when_shown` on items hidden on inactive spaces or displays ([Tricks.md](sketchybar-raw/docs/config/Tricks.md)).
- Prefer `--subscribe` event triggers over tight `update_freq` polling intervals ([Tricks.md](sketchybar-raw/docs/config/Tricks.md)).
- Remove `alias` items for apps that do not stay running ([Tricks.md](sketchybar-raw/docs/config/Tricks.md)).
- Use a compiled `mach_helper` (`v2.9.0+`) for high-frequency IPC workloads ([Tricks.md](sketchybar-raw/docs/config/Tricks.md)).

### Icon Discovery

- **Hack Nerd Font:** Default font. Browse glyphs on the Nerd Font cheat sheet ([Tricks.md](sketchybar-raw/docs/config/Tricks.md)).
- **Apple SF Symbols:** Install via `brew install --cask sf-symbols` and copy symbols directly ([Tricks.md](sketchybar-raw/docs/config/Tricks.md)).
- **App Icons:** Community `sketchybar-app-font` maps running macOS apps to glyphs ([Tricks.md](sketchybar-raw/docs/config/Tricks.md)).

## Debugging Workflow

1. Stop `brew services stop sketchybar` and run `sketchybar` directly in the terminal to inspect stdout/stderr ([Tricks.md](sketchybar-raw/docs/config/Tricks.md)).
2. Check for trailing spaces after `\` line continuations ([Tricks.md](sketchybar-raw/docs/config/Tricks.md)).
3. Verify executable permissions with `chmod +x ~/.config/sketchybar/plugins/*.sh` ([Tricks.md](sketchybar-raw/docs/config/Tricks.md)).
4. Test individual plugin scripts in the shell with sample env vars (`NAME=... SENDER=... INFO=... ./plugin.sh`) ([Tricks.md](sketchybar-raw/docs/config/Tricks.md)).
5. Inspect live runtime state using `sketchybar --query <item>` ([Tricks.md](sketchybar-raw/docs/config/Tricks.md)).
