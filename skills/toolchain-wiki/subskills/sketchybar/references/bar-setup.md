### Overview

SketchyBar replaces or complements the macOS menu bar using a runtime daemon driven by CLI commands.
The executable startup script `~/.config/sketchybar/sketchybarrc` initializes the bar, defaults, and items at launch.

### Specifications & Requirements

- **Prerequisites:** Enable **Displays have separate Spaces** under **System Settings -> Desktop & Dock** ([setup.md](sketchybar-raw/docs/setup.md)).
- **Dependencies:** macOS and optional `font-hack-nerd-font` for default icons ([setup.md](sketchybar-raw/docs/setup.md)). Starter space click scripts reference optional `yabai` ([default-examples.md](sketchybar-raw/_supplementary/supplementary/default-examples.md)).
- **Constraints:** Reference plugins by absolute path (`$CONFIG_DIR/plugins/...`) and set executable bits with `chmod +x` ([setup.md](sketchybar-raw/docs/setup.md)).

### Installation and Service Management

Install with Homebrew and copy the starter files:

```bash
brew tap FelixKratz/formulae
brew install sketchybar
brew install --cask font-hack-nerd-font

mkdir -p ~/.config/sketchybar/plugins
cp "$(brew --prefix)/share/sketchybar/examples/sketchybarrc" ~/.config/sketchybar/sketchybarrc
cp -r "$(brew --prefix)/share/sketchybar/examples/plugins/" ~/.config/sketchybar/plugins/
```

Manage the bar daemon or test changes in the foreground:

```bash
brew services start sketchybar          # Run automatically at login
sketchybar                              # Run in foreground with verbose logs
sketchybar --config /path/to/rc         # Launch with custom config file
sketchybar --load-font /path/to/font    # Load font from non-standard path
```

To build from source, install Xcode command-line tools and run `make` (`make arm64` or `make x86`) ([setup.md](sketchybar-raw/docs/setup.md)).

## Command: `sketchybar --bar`

- **Library/Package:** sketchybar
- **Language/Shell:** Bash / Zsh

### Syntax

```bash
sketchybar --bar <setting>=<value> ... <setting>=<value>
```

### Description

Configures global appearance, geometry, notch handling, and display placement ([Bar.md](sketchybar-raw/docs/config/Bar.md)).
Live CLI calls apply immediately for interactive tuning before persisting them in `sketchybarrc` ([Bar.md](sketchybar-raw/docs/config/Bar.md)).

### Configuration Parameters

| Parameter | Type | Default | Description |
| :--- | :--- | :--- | :--- |
| `color` | `<argb_hex>` | `0x44000000` | Bar background color |
| `border_color` | `<argb_hex>` | `0xffff0000` | Bar border color |
| `position` | `top`, `bottom` | `top` | Screen edge placement |
| `height` | `<integer>` | `25` | Bar height in points |
| `notch_display_height` | `<integer>` | `0` | Height override on notched displays |
| `margin` | `<integer>` | `0` | Outer margin around the bar |
| `y_offset` | `<integer>` | `0` | Vertical offset from default position |
| `corner_radius` | `<positive_integer>` | `0` | Bar corner radius |
| `border_width` | `<positive_integer>` | `0` | Bar border width |
| `blur_radius` | `<positive_integer>` | `0` | Background blur radius |
| `padding_left` | `<positive_integer>` | `0` | Left padding before leftmost item |
| `padding_right` | `<positive_integer>` | `0` | Right padding after rightmost item |
| `notch_width` | `<positive_integer>` | `200` | Notch width reserved on internal display |
| `notch_offset` | `<positive_integer>` | `0` | Extra `y_offset` on notched displays |
| `display` | `main`, `all`, `<positive_integer list>` | `all` | Target displays |
| `hidden` | `<boolean>`, `current` | `off` | Hide all bars or active bar |
| `topmost` | `<boolean>`, `window` | `off` | Draw over everything or windows only |
| `sticky` | `<boolean>` | `on` | Keep bar visible across spaces |
| `font_smoothing` | `<boolean>` | `off` | Enable font smoothing |
| `shadow` | `<boolean>` | `off` | Draw drop shadow under bar |

## Reloading and Multiple Bars

### Reload and Hotload

```bash
sketchybar --reload                     # Reload active sketchybarrc
sketchybar --reload /path/to/rc         # Load a different config file
sketchybar --hotload on                 # Watch config directory for changes
```

Hotload monitors the current config directory and reloads automatically on edits ([Reload.md](sketchybar-raw/docs/config/Reload.md)).

### Multiple Independent Bars

SketchyBar keys each instance name from `argv[0]` via symlink ([Tricks.md](sketchybar-raw/docs/config/Tricks.md)):

```bash
ln -s "$(which sketchybar)" "$(dirname "$(which sketchybar)")/bottom_bar"
bottom_bar --bar position=bottom color=0xffff0000
```

The second bar reads `$HOME/.config/bottom_bar/` and exports `BAR_NAME=bottom_bar` to its scripts ([Tricks.md](sketchybar-raw/docs/config/Tricks.md)).
