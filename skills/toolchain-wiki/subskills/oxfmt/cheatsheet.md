## Decision rules

| When you need to                              | Do this                                              | Because                                              |
| --------------------------------------------- | ---------------------------------------------------- | ---------------------------------------------------- |
| gate formatting in CI                         | `oxfmt --check .`                                    | exits non-zero when files need formatting            |
| fix formatting locally                        | `oxfmt .` (`pnpm run format:fix`)                    | writes in place; default mode                        |
| list files that would change                  | `oxfmt --list-different`                             | read-only preview without touching files             |
| debug single-threaded CI failures             | `oxfmt --check . --threads 1`                        | removes parallelism as a variable                    |
| use a non-default config                      | `oxfmt -c path/to/config.json`                       | disables nested lookup; explicit wins                |
| skip nested config for speed                  | `oxfmt --disable-nested-config`                      | only cwd lookup; single resolve                      |
| scaffold a new config                         | `oxfmt --init`                                       | writes `.oxfmtrc.json` with defaults                 |
| migrate from Prettier or Biome                | `oxfmt --migrate prettier` (or `biome`)              | converts `.prettierrc` / `biome.json` automatically  |
| include `node_modules`                        | `oxfmt --with-node-modules`                          | skipped by default; opt in explicitly                |
| format stdin in editors                       | `oxfmt --stdin-filepath <PATH>`                      | infers parser from the given path                    |

## Trade-off matrices

### --check vs --write vs --list-different

| Flag               | Mutates | Exit code on diff | When to use                          |
| ------------------ | ------- | ----------------- | ------------------------------------ |
| `--check`          | No      | Non-zero          | CI gate (`pnpm run format`)          |
| `--write` (default)| Yes     | Zero              | local fix (`pnpm run format:fix`)    |
| `--list-different` | No      | Non-zero          | preview what `--write` would change  |

### Config file formats

| Format              | Typing / autocomplete | When to use                              |
| ------------------- | --------------------- | ---------------------------------------- |
| `.oxfmtrc.json`     | via `$schema`         | scaffold default; deterministic bytes    |
| `.oxfmtrc.jsonc`    | via `$schema` + comments | hand-maintained configs with comments |
| `oxfmt.config.ts`   | `defineConfig`        | programmatic config; needs TS runtime    |

### sortImports vs sortPackageJson vs sortTailwindcss

| Option            | Default  | Scope                          |
| ----------------- | -------- | ------------------------------ |
| `sortImports`     | disabled | import statement order         |
| `sortTailwindcss` | disabled | Tailwind class order           |
| `sortPackageJson` | enabled  | `package.json` field order     |

## Tells and smells

### Tells (healthy)

- `pnpm run format` passes on a clean checkout.
- `.oxfmtrc.json` contains only `$schema` (scaffold default).
- `pnpm run lint && pnpm run format && pnpm run typecheck && pnpm test` all green.
- No `prettier` or `biome` configs remain after migration.

### Smells (problems)

| Smell                                  | Cause                                   | Fix                                              |
| -------------------------------------- | --------------------------------------- | ------------------------------------------------ |
| `pnpm run format` fails after checkout | files not formatted before push         | run `oxfmt .`, commit result                     |
| per-package format drift               | nearest config wins; nested override    | check for nested `.oxfmtrc.json`; use `-c`       |
| ignored files still formatted          | `ignorePatterns` missing or misquoted   | add globs; quote `!`-excludes for shell          |
| slow formatting in monorepo            | nested config lookup per directory      | `oxfmt --disable-nested-config`                  |
| Prettier plugin behavior missing       | oxfmt has no plugins by design          | check unsupported-features page; keep Prettier for that edge |

## Quick reference: config keys

| Key                | Default  | Purpose                        |
| ------------------ | -------- | ------------------------------ |
| `printWidth`       | 100      | line width limit               |
| `tabWidth`         | 2        | spaces per indent              |
| `useTabs`          | false    | tabs vs spaces                 |
| `semi`             | true     | semicolons                     |
| `singleQuote`      | false    | quote style                    |
| `trailingComma`    | "all"    | multi-line trailing commas     |
| `endOfLine`        | "lf"     | lf/crlf                        |
| `insertFinalNewline` | true   | final newline                  |
| `ignorePatterns`   | []       | globs to exclude               |
| `embedded`         | —        | embedded formatting (CSS-in-JS, GraphQL) |

## Quick reference: CLI

| Command                              | What it does                              |
| ------------------------------------ | ----------------------------------------- |
| `oxfmt .`                            | format in place (default)                 |
| `oxfmt --check .`                    | CI gate; fails when unformatted           |
| `oxfmt --list-different`             | list files that would change              |
| `oxfmt --init`                       | create `.oxfmtrc.json` with defaults      |
| `oxfmt --migrate prettier\|biome`     | convert foreign config to `.oxfmtrc.json` |
| `oxfmt -c <path>`                    | use explicit config; skip nested lookup   |
| `oxfmt --disable-nested-config`      | cwd-only config lookup                    |
| `oxfmt --lsp`                        | start LSP server for editors              |
| `oxfmt --stdin-filepath <PATH>`      | format stdin; infer parser from path      |
