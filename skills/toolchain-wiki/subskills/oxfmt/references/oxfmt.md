## Install & scripts (scaffold wiring)

```bash
pnpm add -D oxfmt   # scaffold pins >=0.15 via package.json devDependencies
```

`package.json` scripts generated by `scaffold.py` (`build_package_json` — see `scaffold.py` for full `devDependencies` incl. `tsx`, `@types/node`, `@semantic-release/*`):

```json
{
  "scripts": {
    "lint": "oxlint .",
    "format": "oxfmt --check .",
    "format:fix": "oxfmt .",
    "typecheck": "tsc --noEmit",
    "test": "vitest run"
  }
}
```

Run:

```bash
pnpm run format        # oxfmt --check .  (CI gate: fails if not formatted)
pnpm run format:fix    # oxfmt .  (write in place, default mode)
oxfmt --check          # check without writing + stats
oxfmt --list-different # list files that would change
oxfmt --write          # explicit write (default)
```

Scaffold verify gate is `pnpm run format` → `oxfmt --check .`.

## Config discovery

Oxfmt walks up from each formatted file; nearest config wins (enables per-package overrides). One config per directory.

Supported filenames (JSON or JS/TS):

- `.oxfmtrc.json` / `.oxfmtrc.jsonc`
- `oxfmt.config.ts` / `oxfmt.config.mts` (also `.cts`, `.js`, `.mjs`, `.cjs` when passed via `-c`)

Search order:

```bash
oxfmt --init                         # init .oxfmtrc.json with defaults
oxfmt -c path/to/config.json         # explicit, disables nested lookup
oxfmt --disable-nested-config        # only cwd lookup (faster, single resolve)
```

Scaffold default (`OXFMT_JSON` in `scaffold.py`):

```json
{
  "$schema": "./node_modules/oxfmt/configuration_schema.json"
}
```

Minimal override:

```json
{
  "$schema": "./node_modules/oxfmt/configuration_schema.json",
  "printWidth": 80
}
```

TypeScript config (optional `defineConfig` for typing/autocomplete):

```ts
import { defineConfig } from 'oxfmt';
export default defineConfig({ printWidth: 80 });
```

`$schema` enables editor validation. Add to `.oxfmtrc.json` for LSP.

## Top-level config fields

| Field                | Default  | Purpose                                  |
| -------------------- | -------- | ---------------------------------------- |
| `printWidth`         | 100      | line width limit                         |
| `tabWidth`           | 2        | spaces per indent                        |
| `useTabs`            | false    | tabs vs spaces                           |
| `semi`               | true     | semicolons                               |
| `singleQuote`        | false    | quote style                              |
| `trailingComma`      | "all"    | multi-line trailing commas               |
| `endOfLine`          | "lf"     | lf/crlf                                  |
| `insertFinalNewline` | true     | final newline                            |
| `bracketSpacing`     | true     | `{ foo }` spacing                        |
| `bracketSameLine`    | false    | `>` on new line                          |
| `arrowParens`        | "always" | `(x) =>` vs `x =>`                       |
| `ignorePatterns`     | []       | globs to exclude                         |
| `sortImports`        | disabled | import sorting                           |
| `sortTailwindcss`    | disabled | Tailwind class sorting                   |
| `sortPackageJson`    | enabled  | package.json field sorting               |
| `embedded`           |          | embedded formatting (CSS-in-JS, GraphQL) |

Full → `011-config-file-reference.md` / `012-generated-config.md` and <https://oxc.rs/docs/guide/usage/formatter/config-file-reference>

`ignorePatterns` example:

```json
{ "ignorePatterns": ["dist/**", "*.min.js"] }
```

`.editorconfig` mapping (nearest file only, `root=true` ignored, no merge):

```
[*] indent_size=4 → tabWidth
indent_style=tab → useTabs
max_line_length → printWidth
end_of_line → endOfLine, insert_final_newline → insertFinalNewline
[*]  [*.{js,ts}] sections supported, globs honored
```

## Batteries included (no plugins needed)

- Import sorting: `sortImports`
- Tailwind class sorting: `sortTailwindcss`
- `package.json` field sorting: `sortPackageJson` (enabled by default)
- Embedded formatting: CSS-in-JS, GraphQL etc. → see `013-embedded-formatting.md` and <https://oxc.rs/docs/guide/usage/formatter/embedded-formatting>
- Language support: JS/JSX/TS/TSX, JSON/JSONC/JSON5, YAML, TOML, HTML, Vue, Svelte, CSS/SCSS/Less, Markdown/MDX, GraphQL, Handlebars etc. — native Rust for most; see <https://oxc.rs/docs/guide/usage/formatter/language-support> and compatibility matrix.

## Prettier compatibility

Oxfmt CLI follows Prettier conventions; most scripts need little change. Matches Prettier JS formatting (100% conformance tests). Differences are bugs — report vs <https://github.com/oxc-project/oxc/issues/18717>. No extra deps.

Migrate from Prettier/Biome:

```bash
oxfmt --migrate prettier   # or biome
# converts .prettierrc / biome.json → .oxfmtrc.json
```

## CLI reference

```
oxfmt [-c <PATH>] [PATH]...

 Mode:
      --init                    init .oxfmtrc.json
      --migrate <prettier|biome>
      --lsp                     start LSP server
      --stdin-filepath <PATH>   infer parser for stdin

 Output:
      --write                   write in place (default)
      --check                   check + stats, no write
      --list-different          list files that would change

 Config:
  -c, --config <PATH>           config file (.json/.ts/.js)
      --disable-nested-config   cwd-only lookup

 Ignore:
      --ignore-path <PATH>      .gitignore/.prettierignore by default, repeatable
      --with-node-modules       include node_modules (skipped by default)

 Runtime:
      --no-error-on-unmatched-pattern
      --threads <INT>           1 = single core

 PATH  file/dir/glob, !-excluded, default "."
  -h/--help, -V/--version
```

Verify gate:

```bash
pnpm run format                # oxfmt --check .  → exit non-zero if unformatted
oxfmt --check . --threads 1    # single-thread CI debug
```

CI example (from `ci-scaffolding` Node verify job, `pnpm run coverage` when `--with-coverage`):

```yaml
- run: pnpm install --no-frozen-lockfile
- run: pnpm run lint && pnpm run format && pnpm run typecheck && pnpm test # or pnpm run coverage
```

## Ignore & unsupported

- Default ignore: `.gitignore` + `.prettierignore` + `node_modules` (use `--with-node-modules` to include).
- Unsupported features list → <https://oxc.rs/docs/guide/usage/formatter/unsupported-features> (check when migrating).
- Glob exclude: `'!**/fixtures/*.js'` (quote for shell).

## Notes for scaffold consumers

- Deterministic files are `.oxfmtrc.json` (empty schema) + `package.json` scripts; scaffold owns bytes via `scaffold.py --flavor typescript`. Do not hand-copy — preview with `--dry-run`.
- Formatting gate is `oxfmt --check .`; fix is `oxfmt .` (`pnpm run format:fix`). Keep both in `package.json` for local/CI symmetry.
- For editor setup: point LSP to `oxfmt --lsp` or install Oxc VS Code extension; see <https://oxc.rs/docs/guide/usage/formatter/editors>
- For coding agents integration (Oxlint+Oxfmt): <https://oxc.rs/docs/guide/usage/coding-agents.md> + `014-coding-agents.md`
- Variants/coverage: see `README.md` / `oxc-introduction.md` — `lib`/`cli`/`pi-extension` entries and `vitest.config.ts` thresholds; formatter unchanged.
