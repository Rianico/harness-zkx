## Defaults & conversion
### `default(value, default_value='', boolean=False)`
Returns `default_value` when `value` is undefined, otherwise `value` [006-templates.md#default](jinja-raw/006-templates.md). Alias `d`.

```jinja
{{ my_variable|default('my_variable is not defined') }}
{{ ''|default('the string was empty', true) }}
```

The second parameter `true` also replaces values that evaluate false, such as an empty string. With `ChainableUndefined` the filter works on nested undefined values in a chain.
### `int(value, default=0, base=10)`
Converts to integer; returns `default` when conversion fails [006-templates.md#int](jinja-raw/006-templates.md). `base` handles prefixes such as `0b`, `0o` and `0x` for bases 2, 8 and 16; the base is ignored for decimal numbers and non-string values.

```jinja
{{ "0x1f"|int(0, 16) }}
{{ "nope"|int(default=-1) }}
```
### `float(value, default=0.0)`, `string(s, /)`, `list(value)`, `abs(x, /)`
`float` converts and returns `default` (0.0) on failure [006-templates.md#float](jinja-raw/006-templates.md). `string` converts an object to a string and preserves `Markup` rather than demoting it to `str` [006-templates.md#string](jinja-raw/006-templates.md). `list` converts to a list; a string becomes a list of characters [006-templates.md#list](jinja-raw/006-templates.md). `abs` returns the absolute value [006-templates.md#abs](jinja-raw/006-templates.md).
## Strings — case and whitespace
### `replace(s, old, new, count=None)`
Replaces every occurrence unless `count` limits the number of replacements [006-templates.md#replace](jinja-raw/006-templates.md).

```jinja
{{ "Hello World"|replace("Hello", "Goodbye") }}
    -> Goodbye World
{{ "aaaaargh"|replace("a", "d'oh, ", 2) }}
    -> d'oh, d'oh, aaargh
```
### `indent(s, width=4, first=False, blank=False)`
Indents each line by 4 spaces; the first line and blank lines stay unindented by default [006-templates.md#indent](jinja-raw/006-templates.md).

| Parameter | Effect |
| --- | --- |
| `width` | Number of spaces, or a string, to indent by |
| `first` | Do not skip indenting the first line |
| `blank` | Do not skip indenting empty lines |

Since 3.0 `width` may be a string, and the `indentfirst` argument was renamed to `first`.
### `truncate(s, length=255, killwords=False, end='...', leeway=None)`
Truncates to `length` and appends `end` when truncation happened [006-templates.md#truncate](jinja-raw/006-templates.md). With `killwords` false the last word is discarded instead of cut.

```jinja
{{ "foo bar baz qux"|truncate(9) }}          -> "foo..."
{{ "foo bar baz qux"|truncate(9, True) }}    -> "foo ba..."
{{ "foo bar baz qux"|truncate(11) }}         -> "foo bar baz qux"
{{ "foo bar baz qux"|truncate(11, False, '...', 0) }} -> "foo bar..."
```

Strings exceeding `length` only inside the `leeway` margin are not truncated. Default leeway is 5, configurable via the `truncate.leeway` policy.
### `wordwrap(s, width=79, break_long_words=True, wrapstring=None, break_on_hyphens=True)`
Wraps a string to `width`; existing newlines are treated as paragraphs wrapped separately [006-templates.md#wordwrap](jinja-raw/006-templates.md). `wrapstring` joins each wrapped line and defaults to `Environment.newline_sequence`.
### `capitalize(s)`, `lower(s)`, `upper(s)`, `title(s)`, `trim(value, chars=None)`
`capitalize` uppercases the first character and lowercases the rest [006-templates.md#capitalize](jinja-raw/006-templates.md). `title` uppercases word starts and lowercases the remaining characters [006-templates.md#title](jinja-raw/006-templates.md). `trim` strips leading and trailing characters, whitespace by default [006-templates.md#trim](jinja-raw/006-templates.md).
### `center(value, width=80)`, `striptags(value)`, `wordcount(s)`
`center` centers the value in a field of the given width [006-templates.md#center](jinja-raw/006-templates.md). `striptags` strips SGML/XML tags and replaces adjacent whitespace by one space [006-templates.md#striptags](jinja-raw/006-templates.md). `wordcount` counts words [006-templates.md#wordcount](jinja-raw/006-templates.md).
## Sequences — order and shape
### `sort(value, reverse=False, case_sensitive=False, attribute=None)`
Sorts an iterable using Python's `sorted()` [006-templates.md#sort](jinja-raw/006-templates.md). The sort is stable, so chained sorts keep the earlier ordering for equal elements.

| Parameter | Effect |
| --- | --- |
| `reverse` | Sort descending instead of ascending |
| `case_sensitive` | Sort upper and lower case strings separately |
| `attribute` | Attribute or key to sort by; supports dot notation, or a comma separated list such as `"age,name"` |

```jinja
{% for user in users|sort(attribute="name")|sort(reverse=true, attribute="age") %}
    ...
{% endfor %}
```
### `unique(value, case_sensitive=False, attribute=None)`
Yields unique items in order of first occurrence [006-templates.md#unique](jinja-raw/006-templates.md).

```jinja
{{ ['foo', 'bar', 'foobar', 'FooBar']|unique|list }}
    -> ['foo', 'bar', 'foobar']
```
### `dictsort(value, case_sensitive=False, by='key', reverse=False)`
Sorts a mapping and yields `(key, value)` pairs [006-templates.md#dictsort](jinja-raw/006-templates.md). Use `dictsort(false, 'value')` to sort by value instead.

```jinja
{% for key, value in mydict|dictsort(reverse=true) %}
    sort the dict by key, case insensitive, reverse order
{% endfor %}
```
### `join(value, d='', attribute=None)`
Concatenates a sequence into a string separated by `d`, empty by default [006-templates.md#join](jinja-raw/006-templates.md).

```jinja
{{ [1, 2, 3]|join('|') }}    -> 1|2|3
{{ users|join(', ', attribute='username') }}
```
### `batch(value, linecount, fill_with=None)`, `slice(value, slices, fill_with=None)`
`batch` returns lists of `linecount` items, padding missing items with `fill_with` [006-templates.md#batch](jinja-raw/006-templates.md). `slice` is the inverse: it returns `slices` lists, filling missing values on the last iteration [006-templates.md#slice](jinja-raw/006-templates.md).

```html+jinja
<table>
{%- for row in items|batch(3, '&nbsp;') %}
  <tr>{%- for column in row %}<td>{{ column }}</td>{%- endfor %}</tr>
{%- endfor %}
</table>
```

```html+jinja
{%- for column in items|slice(3) %}
  <ul class="column-{{ loop.index }}">
  {%- for item in column %}<li>{{ item }}</li>{%- endfor %}
  </ul>
{%- endfor %}
```
### `first(seq)`, `last(seq)`, `random(seq)`, `reverse(value)`
`first` and `last` return the first and last item of a sequence [006-templates.md#first](jinja-raw/006-templates.md) [006-templates.md#last](jinja-raw/006-templates.md). `last` does not work with generators, so convert explicitly.

```jinja
{{ data | selectattr('name', '==', 'Jinja') | list | last }}
```

`random` returns a random item [006-templates.md#random](jinja-raw/006-templates.md). `reverse` reverses a string or returns an iterator over the sequence backwards [006-templates.md#reverse](jinja-raw/006-templates.md).
## Aggregation
### `length(obj, /)`, `sum(iterable, attribute=None, start=0)`
`length` returns the number of items in a container, alias `count` [006-templates.md#length](jinja-raw/006-templates.md). `sum` adds the sequence to `start` (default `0`) and returns `start` for an empty sequence [006-templates.md#sum](jinja-raw/006-templates.md).

```jinja
Total: {{ items|sum(attribute='price') }}
```
### `min(value, case_sensitive=False, attribute=None)`, `max(value, case_sensitive=False, attribute=None)`
Return the smallest or largest item [006-templates.md#min](jinja-raw/006-templates.md) [006-templates.md#max](jinja-raw/006-templates.md). `attribute` picks the object with the min/max value of that attribute.

```jinja
{{ [1, 2, 3]|max }}    -> 3
```
## Objects and attributes
### `attr(obj, name)`
Works like `foo.bar`, but returns undefined instead of falling back to `foo["bar"]` when the attribute is missing [006-templates.md#attr](jinja-raw/006-templates.md).

```jinja
{{ foo|attr("bar") }}
```
### `map(value, *args, **kwargs)`
Applies a filter to every item, or looks up an attribute [006-templates.md#map](jinja-raw/006-templates.md). Passing a filter name and its arguments is equivalent to a generator comprehension such as `(do_lower(x) for x in titles)`.

```jinja
Users on this page: {{ users|map(attribute='username')|join(', ') }}
{{ users|map(attribute="username", default="Anonymous")|join(", ") }}
Users on this page: {{ titles|map('lower')|join(', ') }}
```
### `items(value)`
Returns an iterator over the `(key, value)` items of a mapping. `x|items` matches `x.items()`, but yields an empty iterator for undefined `x` [006-templates.md#items](jinja-raw/006-templates.md). Added in 3.1 for Jinja implementations in other languages.

```html+jinja
{% for key, value in my_dict|items %}
    <dt>{{ key }}
    <dd>{{ value }}
{% endfor %}
```
### `groupby(value, attribute, default=None, case_sensitive=False)`
Groups objects by an attribute using `itertools.groupby()`, sorting values first so each unique value gets a single group [006-templates.md#groupby](jinja-raw/006-templates.md). `attribute` supports dot notation such as `"address.city"`, and `default` supplies a value for objects missing it.

```html+jinja
<ul>{% for group in users|groupby("city") %}
  <li>{{ group.grouper }}: {{ group.list|join(", ") }}
{% endfor %}</ul>
```

`groupby` yields namedtuples of `(grouper, list)`, usable instead of tuple unpacking. Grouping is case-insensitive by default; `case_sensitive=True` separates cases.
## Test-based filtering
### `select(value, *args, **kwargs)`, `reject(value, *args, **kwargs)`
Keep or drop items for which a test succeeds [006-templates.md#select](jinja-raw/006-templates.md) [006-templates.md#reject](jinja-raw/006-templates.md). Without a test each object is evaluated as a boolean, matching `(n for n in numbers if test_odd(n))` and its negation.

```jinja
{{ numbers|select("odd") }}
{{ numbers|select("divisibleby", 3) }}
{{ strings|select("equalto", "mystring") }}
{{ numbers|reject("odd") }}
```
### `selectattr(value, *args, **kwargs)`, `rejectattr(value, *args, **kwargs)`
Same as `select` / `reject`, but the test runs on a named attribute of each object [006-templates.md#selectattr](jinja-raw/006-templates.md) [006-templates.md#rejectattr](jinja-raw/006-templates.md). Both were added in 2.7.

```jinja
{{ users|selectattr("is_active") }}
{{ users|selectattr("email", "none") }}
{{ users|rejectattr("email", "none") }}
```
## Numbers and sizes
### `round(value, precision=0, method='common')`
Rounds to `precision` decimals [006-templates.md#round](jinja-raw/006-templates.md). `'common'` rounds either up or down and is the default; `'ceil'` always rounds up; `'floor'` always rounds down.

```jinja
{{ 42.55|round }}            -> 43.0
{{ 42.55|round(1, 'floor') }} -> 42.5
{{ 42.55|round|int }}        -> 43
```

A float is returned even at precision `0`; pipe through `int` for a real integer.
### `filesizeformat(value, binary=False)`, `format(value, *args, **kwargs)`
`filesizeformat` renders `13 kB`, `4.1 MB`, `102 Bytes` and similar [006-templates.md#filesizeformat](jinja-raw/006-templates.md). Decimal prefixes are the default; `binary=True` switches to Mebi, Gibi and friends. `format` applies values to a printf-style string [006-templates.md#format](jinja-raw/006-templates.md).

```jinja
{{ "%s, %s!"|format(greeting, name) }}    -> Hello, World!
```

The `%` operator or `str.format()` is usually more convenient and efficient.
## Escaping, HTML and URL
### `escape(s, /)`, `forceescape(value)`, `safe(value)`
`escape` replaces `&`, `<`, `>`, `'` and `"` with HTML-safe sequences and returns `Markup`; an `__html__` method is called and its return value assumed safe [006-templates.md#escape](jinja-raw/006-templates.md). Alias `e`. `forceescape` enforces escaping and will probably double escape variables [006-templates.md#forceescape](jinja-raw/006-templates.md). `safe` marks a value as safe, so automatic escaping leaves it untouched [006-templates.md#safe](jinja-raw/006-templates.md).
### `tojson(value, indent=None)`
Serializes an object to JSON and marks it safe to render in HTML [006-templates.md#tojson](jinja-raw/006-templates.md). `indent` is passed to `dumps` for pretty-printing.

> [!WARNING]
> `tojson` output is not safe inside double-quoted HTML attributes. Use single quotes there, or pipe through `|forceescape`.
### `urlize(value, trim_url_limit=None, nofollow=False, target=None, rel=None, extra_schemes=None)`
Turns URLs in text into clickable links [006-templates.md#urlize](jinja-raw/006-templates.md). It recognizes `http://`, `https://`, `www.`, `mailto:` and email addresses.

| Parameter | Effect |
| --- | --- |
| `trim_url_limit` | Shorten displayed URL values to this length |
| `nofollow` | Add the `rel=nofollow` attribute |
| `target` / `rel` | Add the `target` / `rel` attribute |
| `extra_schemes` | Recognize additional schemes |

`extra_schemes` defaults to `env.policies["urlize.extra_schemes"]`, which defaults to no extra schemes. Links without a scheme get `https://` since 3.0. A Markdown library is usually a better choice for comprehensive formatting.
### `urlencode(value)`, `xmlattr(d, autospace=True)`
`urlencode` quotes data for a URL path or query with UTF-8 [006-templates.md#urlencode](jinja-raw/006-templates.md). A string goes to `urllib.parse.quote()`, a dict or iterable of `(key, value)` pairs to `urllib.parse.urlencode()`. When given a string, `/` is not quoted; use `|replace("/", "%2F")` for quoted slashes.

`xmlattr` builds an SGML/XML attribute string from a dict and escapes every value that is neither `none` nor `undefined`, so untrusted input is safe as a value [006-templates.md#xmlattr](jinja-raw/006-templates.md). A space is prepended unless `autospace` is false.

```html+jinja
<ul{{ {'class': 'my_list', 'missing': none,
        'id': 'list-%d'|format(variable)}|xmlattr }}>
```

```html
<ul class="my_list" id="list-42">
```

> [!WARNING]
> Never use user input as keys to `xmlattr`. Keys containing a space, `/`, `>` or `=` raise `ValueError`. Spaces are rejected since 3.1.3; `/`, `>` and `=` since 3.1.4.
### `pprint(value)`
Pretty prints a variable. Useful for debugging [006-templates.md#pprint](jinja-raw/006-templates.md).
## Custom filters

A filter is a Python function whose first argument is the value left of the filter; template arguments are passed after it. `{{ 42|myfilter(23) }}` calls `myfilter(42, 23)` [003-api.md#custom-filters](jinja-raw/003-api.md). Write a function taking at least `value`, then register it in `Environment.filters`.

```python
def datetime_format(value, format="%H:%M %d-%m-%y"):
    return value.strftime(format)

environment.filters["datetime_format"] = datetime_format
```

```jinja
{{ article.pub_date|datetime_format }}
{{ article.pub_date|datetime_format("%B %Y") }}
```

The injected object from a decorator becomes the first argument, so the filtered value moves to second position [003-api.md#custom-filters](jinja-raw/003-api.md).

| Decorator | Passes |
| --- | --- |
| `pass_environment()` | The `Environment` |
| `pass_eval_context()` | The Evaluation Context |
| `pass_context()` | The current `Context` |

```python
import re
from jinja2 import pass_eval_context
from markupsafe import Markup, escape

@pass_eval_context
def nl2br(eval_ctx, value):
    br = Markup("<br>\n") if eval_ctx.autoescape else "<br>\n"
    if eval_ctx.autoescape:
        value = escape(value)
    result = "\n\n".join(
        f"<p>{br.join(p.splitlines())}</p>"
        for p in re.split(r"(?:\r\n|\r(?!\n)|\n){2,}", value)
    )
    return Markup(result) if eval_ctx.autoescape else result
```

Check `eval_ctx.autoescape`, not the environment, when a filter decides whether to escape.

> [!TIP]
> Prefer `pass_eval_context` over `pass_environment` when only the autoescape flag is needed; the eval context holds the computed value for the current template [003-api.md#evaluation-context](jinja-raw/003-api.md).
### Async filters
> [!NOTE]
> The read ranges for this module (003-api.md 1672–1725) do not document async filter registration. A dedicated `async_variant` decorator is named only in the changelog [013-changes.md#changes](jinja-raw/013-changes.md).

With async support enabled, sync methods and filters become wrappers around their corresponding async implementations. For example `render` invokes `async_render`, and `|map` supports async iterables [003-api.md#async-support](jinja-raw/003-api.md). Async support is disabled by default and enabled per environment with `enable_async`; the compiled code then awaits functions and attributes and uses `async for` loops. `|unique` is async-aware since Jinja 3.1, so it can follow another async-aware filter.

**Done when:** you can name a filter, its argument signature and its default behaviour, and you have registered one custom filter in `Environment.filters`.
