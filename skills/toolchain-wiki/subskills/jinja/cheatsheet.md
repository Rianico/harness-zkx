## Decision rules

| When you need to                              | Do this                                              | Because                                              |
| --------------------------------------------- | ---------------------------------------------------- | ---------------------------------------------------- |
| create an environment                         | build `Environment` once at app start                | never per request or per render; loaders cache       |
| escape markup output                          | `autoescape=select_autoescape()`                      | escapes `.html`/`.xml` only; never blanket `|safe`   |
| fail loudly on typos                          | `StrictUndefined` while developing                   | default `Undefined` prints nothing silently          |
| reuse templates with inheritance              | `FileSystemLoader` (not `Template("…")` strings)     | only loaders enable inheritance and caching          |
| control tag whitespace globally               | `trim_blocks` + `lstrip_blocks` on `Environment`    | avoids sprinkling `{%- -%}` through templates        |
| sandbox untrusted templates                   | `SandboxedEnvironment` + audit operator tables       | plain `Environment` executes arbitrary Python        |
| render values instead of text                 | `NativeEnvironment`                                  | returns `int`/`list`/objects, not strings            |
| check syntax fast                             | `Environment().parse(source)`                        | raises `TemplateSyntaxError`; no context needed       |
| smoke-test rendering                          | render with minimal context; grep for literal `{{`   | leftover delimiters mean failed resolution           |
| translate templates                           | `jinja2.ext.i18n` + `install_gettext_*`              | `{% trans %}` plus Babel filters                     |
| add statement-level code                      | `jinja2.ext.do` (`{% do %}`)                         | expression statements without output                 |
| break out of loops                            | `jinja2.ext.loopcontrols`                            | `{% break %}`, `{% continue %}`                      |

## Trade-off matrices

### Undefined types: which to use

| Type                 | Missing name renders | Other operations | When to use                  |
| -------------------- | -------------------- | ---------------- | ---------------------------- |
| `Undefined` (default)| empty string         | raise            | production; silent fallback  |
| `StrictUndefined`    | raise                | raise            | development; typos fail loudly|
| `ChainableUndefined` | empty, chainable     | empty            | deep attribute chains        |

### Loader choice

| Loader            | Source               | Inheritance + cache | When to use                  |
| ----------------- | -------------------- | ------------------- | ---------------------------- |
| `FileSystemLoader`| directory on disk    | yes                 | apps with template files     |
| `PackageLoader`   | Python package       | yes                 | distributable template packs |
| `DictLoader`      | in-memory dict       | yes                 | tests, small snippets        |
| `Template("…")`   | string               | no                  | one-off renders only         |

### autoescape settings

| Setting                     | Escapes              | When to use                          |
| --------------------------- | -------------------- | ------------------------------------ |
| `False` (default)           | nothing              | plain-text templates                 |
| `True`                      | everything           | all output is markup                 |
| `select_autoescape()`       | `.html`/`.xml` only  | mixed template directories           |

Never wrap user input in `|safe` or `Markup`.

### SandboxedEnvironment vs NativeEnvironment

| Aspect        | `SandboxedEnvironment`              | `NativeEnvironment`              |
| ------------- | ----------------------------------- | -------------------------------- |
| **Purpose**   | restrict untrusted templates        | render native Python values      |
| **Output**    | strings (safe runtime)              | `int`/`list`/objects             |
| **Risk**      | not a security sandbox by default   | executes template code normally  |
| **Tuning**    | `SecurityPolicy`, `intercepted_binops` | none needed                   |

## Tells and smells

### Tells (healthy)

- One `Environment` built at app start; reused everywhere.
- `autoescape=select_autoescape()` set for markup apps.
- `StrictUndefined` in dev; default `Undefined` in prod.
- Rendered output contains no literal `{{` or `{%`.
- Version-sensitive answers confirmed via `jinja2.__version__`.

### Smells (problems)

| Smell                                  | Cause                                   | Fix                                              |
| -------------------------------------- | --------------------------------------- | ------------------------------------------------ |
| typos render as empty output           | default `Undefined` swallows names      | use `StrictUndefined` while developing           |
| user input renders unescaped           | missing `autoescape` or stray `|safe`   | set `select_autoescape()`; remove `|safe`         |
| `{% extends %}` fails                  | `Template("…")` string has no loader    | switch to `FileSystemLoader`                     |
| extra blank lines in output            | tag-only lines keep newlines            | set `trim_blocks` + `lstrip_blocks`              |
| sandbox bypassed                       | default operator tables too permissive  | audit `is_safe_attribute` for your threat model  |
| `TemplateNotFound` in Flask/Django     | framework loader miswired               | check framework wiring before template syntax    |

## Quick reference: delimiters

| Syntax    | Meaning                                      |
| --------- | -------------------------------------------- |
| `{{ … }}` | expression printed to output                 |
| `{% … %}` | statement: control flow, inheritance, macros |
| `{# … #}` | comment, not in output                       |

## Quick reference: composition

| Tag                                        | What it does                          |
| ------------------------------------------ | ------------------------------------- |
| `{% extends "base.html" %}`                | inherit layout                        |
| `{% block name %}…{% endblock %}`          | overridable region                    |
| `{{ super() }}`                            | render parent block content           |
| `{% include "f.html" %}`                   | inline another template              |
| `{% import "m.html" as m %}`                | import macros (no context by default) |
| `{% from "m.html" import f %}`             | import one macro                      |
| `{% macro f(a, b='') %}…{% endmacro %}`    | reusable markup block                 |
| `{% call f() %}…{% endcall %}`              | call block with caller content         |

## Quick reference: most-used filters

| Filter                        | Effect                                  |
| ----------------------------- | --------------------------------------- |
| `default(v, '', boolean=False)`| fallback when undefined (or falsy)      |
| `join`, `length`, `first`, `last` | sequence shaping                     |
| `map`, `select`, `rejectattr` | lazy filtering and transforming         |
| `sort`, `groupby`, `unique`   | ordering                                |
| `title`, `trim`, `truncate`   | text shaping                            |
| `tojson`, `urlencode`         | output shaping                          |
| `int`, `float`, `round`, `sum`| numbers                                 |
| `escape`, `safe`              | escaping (`safe` = trusted only)        |
| `batch`, `slice`, `items`     | grouping and access                     |

## Quick reference: tests and globals

Tests: `defined`, `none`, `boolean`, `number`, `string`, `sequence`, `mapping`, `iterable`, `odd`, `even`, `divisibleby`, `eq`, `sameas`, `escaped`.

Globals: `range()`, `dict()`, `lipsum()`, `cycler()`, `joiner()`, `namespace()`.

## Quick reference: Environment options

| Option                        | Default          | Use it for                     |
| ----------------------------- | ---------------- | ------------------------------ |
| `loader`                      | `None`           | template resolution            |
| `autoescape`                  | `False`          | `select_autoescape()` for markup|
| `undefined`                   | `Undefined`      | `StrictUndefined` in dev       |
| `trim_blocks`, `lstrip_blocks`| `False`          | tag-only line whitespace       |
| `keep_trailing_newline`       | `False`          | exact output bytes             |
| `extensions`                  | `[]`             | i18n, `do`, loop controls      |
| `cache_size`                  | `400`            | `-1` never clear, `0` always recompile |
| `enable_async`                | `False`          | async templates                |
