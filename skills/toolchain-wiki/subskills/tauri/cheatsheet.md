## Decision rules

| When you need to | Do this | Because |
| --- | --- | --- |
| call Rust from frontend | define `#[tauri::command]` and register in `invoke_handler` | registers command for frontend `invoke()` calls |
| share mutable backend state | register `Mutex<T>` or `RwLock<T>` via `app.manage()` | injects thread-safe state into command handlers |
| push events to frontend | import `tauri::Emitter` and call `app.emit()` | delivers event payloads to webview listeners |
| listen to frontend events in Rust | import `tauri::Listener` and call `app.listen()` | provides access to event subscription methods |
| mutate window state from frontend | grant explicit permissions like `core:window:allow-show` | `core:window:default` only permits state queries |
| access native OS features | install plugin via `pnpm tauri add <plugin>` | configures crate, npm package, and capability permissions |
| configure custom system tray | enable `tray-icon` cargo feature in `Cargo.toml` | imports from `tauri::tray` fail to compile without it |
| restrict filesystem access | define path globs under capability `allow` list | confines frontend file operations to safe directories |
| load local assets in webview | use `http://asset.localhost` protocol | isolates asset requests without breaking webview security |

## CLI Quick Lookup

| Task | Command | Flags | Notes |
| ---- | ------- | ----- | ----- |
| Start dev app | `pnpm tauri dev` | `--target <TRIPLE>`, `--no-watch` | Starts frontend dev server and webview with hot reload |
| Build release | `pnpm tauri build` | `--debug`, `--bundles <LIST>` | Emits production binary and platform installers |
| Generate icons | `pnpm tauri icon <FILE>` | `-o src-tauri/icons`, `--png` | Creates icon set from 1024x1024 PNG source |
| System info | `pnpm tauri info` | None | Diagnostics for OS, webview, and Rust toolchain |
| Add plugin | `pnpm tauri add <PLUGIN>` | None | Installs crate and frontend dependency |
| Scaffold plugin | `npx @tauri-apps/cli plugin new <NAME>` | `--android`, `--ios`, `--no-api` | Generates plugin workspace |

## Trait Imports Reference

Rust methods require their defining traits in scope. Always check imports if methods fail to resolve.

| Trait | Required Import | Available Methods |
| ----- | --------------- | ----------------- |
| `Manager` | `use tauri::Manager;` | `app.get_webview_window("label")`, `app.manage(state)`, `app.state::<T>()`, `app.path()` |
| `Emitter` | `use tauri::Emitter;` | `app.emit("event", payload)`, `app.emit_to("target", "event", payload)`, `app.emit_filter(...)` |
| `Listener` | `use tauri::Listener;` | `app.listen("event", handler)`, `app.listen_any("event", handler)`, `app.unlisten(id)` |

## Command and Invoke Patterns

### Rust Command Definition

```rust
// src-tauri/src/commands.rs
use tauri::State;
use std::sync::Mutex;

#[derive(Default)]
pub struct AppState {
    pub count: u32,
}

#[tauri::command]
pub fn increment_counter(
    step: u32,
    state: State<'_, Mutex<AppState>>,
) -> Result<u32, String> {
    let mut data = state.lock().map_err(|e| e.to_string())?;
    data.count += step;
    Ok(data.count)
}
```

### Handler Registration

```rust
// src-tauri/src/lib.rs
mod commands;

pub fn run() {
    tauri::Builder::default()
        .setup(|app| {
            use tauri::Manager;
            app.manage(std::sync::Mutex::new(commands::AppState::default()));
            Ok(())
        })
        .invoke_handler(tauri::generate_handler![commands::increment_counter])
        .run(tauri::generate_context!())
        .expect("failed to start app");
}
```

### Frontend Invoke

```typescript
import { invoke } from '@tauri-apps/api/core';

// Pass arguments with camelCase keys
const nextCount = await invoke<number>('increment_counter', {
  step: 1,
});
console.log('Next counter value:', nextCount);
```

## Capabilities and Permissions

Capabilities map permissions to window labels in `src-tauri/capabilities/default.json`.

```json
{
  "$schema": "../gen/schemas/desktop-schema.json",
  "identifier": "default",
  "windows": ["main"],
  "permissions": [
    "core:default",
    "opener:default",
    "dialog:default",
    {
      "identifier": "fs:allow-read-file",
      "allow": [{ "path": "$APPDATA/**" }]
    }
  ]
}
```

### Common Permission Identifiers

| Identifier | Description | Included By Default? |
| ---------- | ----------- | -------------------- |
| `core:default` | App, event, image, menu, path, tray, and window basics | No (must add to capability) |
| `opener:default` | Open URLs and files with system apps | No (requires plugin install) |
| `fs:default` | File system operations | No (requires plugin install) |
| `dialog:default` | Native dialogs and file pickers | No (requires plugin install) |
| `shell:default` | Spawn external processes | No (requires plugin install) |

## Plugin Registration Pattern

```rust
// src-tauri/src/lib.rs
pub fn run() {
    tauri::Builder::default()
        .plugin(tauri_plugin_opener::init())
        .plugin(tauri_plugin_fs::init())
        .plugin(tauri_plugin_dialog::init())
        .run(tauri::generate_context!())
        .expect("error running app");
}
```
