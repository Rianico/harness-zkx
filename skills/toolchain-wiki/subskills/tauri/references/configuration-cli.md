## Configuration File Schema

Tauri reads its build settings and window definitions from `src-tauri/tauri.conf.json`.

```json
{
  "$schema": "https://schema.tauri.app/config/2",
  "productName": "desktop-client",
  "version": "1.0.0",
  "identifier": "com.company.desktopclient",
  "build": {
    "beforeDevCommand": "pnpm run dev",
    "devUrl": "http://localhost:5173",
    "beforeBuildCommand": "pnpm run build",
    "frontendDist": "../dist"
  },
  "app": {
    "withGlobalTauri": false,
    "security": {
      "csp": "default-src 'self'; script-src 'self'; style-src 'self' 'unsafe-inline'"
    },
    "windows": [
      {
        "title": "Desktop Client",
        "width": 1024,
        "height": 768,
        "resizable": true,
        "fullscreen": false
      }
    ]
  },
  "bundle": {
    "active": true,
    "targets": "all",
    "icon": [
      "icons/32x32.png",
      "icons/128x128.png",
      "icons/128x128@2x.png",
      "icons/icon.icns",
      "icons/icon.ico"
    ]
  },
  "plugins": {}
}
```

## Schema Sections

### Top-Level Keys

| Field | Type | Description |
| ----- | ---- | ----------- |
| `productName` | `string` | Display name for the application executable and bundles. |
| `version` | `string` | Semver version string (e.g. `"1.0.0"`). |
| `identifier` | `string` | Unique reverse-DNS identifier (e.g. `"com.example.app"`). |
| `mainBinaryName` | `string` | Name of the primary binary output if different from `productName`. |

### Build Object (`build`)

| Field | Type | Description |
| ----- | ---- | ----------- |
| `beforeDevCommand` | `string` | Shell command executed before launching the development webview (e.g. `"pnpm run dev"`). |
| `devUrl` | `string` | URL of the frontend development server. Replaces v1 `devPath`. |
| `beforeBuildCommand` | `string` | Shell command executed before compiling the release binary (e.g. `"pnpm run build"`). |
| `frontendDist` | `string` | Directory containing built frontend assets. Replaces v1 `distDir`. |

### App Object (`app`)

| Field | Type | Description |
| ----- | ---- | ----------- |
| `withGlobalTauri` | `boolean` | Exposes `window.__TAURI__` global object if `true`. Defaults to `false`. |
| `security` | `object` | Configures CSP, asset protocols, and capabilities. |
| `windows` | `WindowConfig[]` | List of application windows spawned on startup. |

### Bundle Object (`bundle`)

| Field | Type | Description |
| ----- | ---- | ----------- |
| `active` | `boolean` | Activates bundle creation during release builds. Defaults to `true`. |
| `targets` | `string \| string[]` | Output installer targets: `"all"`, `"deb"`, `"appimage"`, `"dmg"`, `"nsis"`, `"msi"`. |
| `icon` | `string[]` | Paths to application icons relative to `src-tauri`. |
| `createUpdaterArtifacts` | `boolean \| "v1Compatible"` | Generates signed update archives for the updater plugin. |

## CLI Commands

Invoke the Tauri CLI via your package manager or directly through Cargo:

```bash
# Package manager invocation
pnpm tauri <command>

# Direct cargo invocation
cargo tauri <command>
```

### Development (`tauri dev`)

Runs the frontend development server and opens the native application window with hot reloading.

```bash
pnpm tauri dev
```

Key options:
- `--config <JSON>`: Merges inline JSON configuration into `tauri.conf.json`.
- `--target <TRIPLE>`: Targets a specific compilation architecture (e.g. `x86_64-pc-windows-msvc`).
- `--no-watch`: Disables file watching and auto-recompilation.

### Production Build (`tauri build`)

Compiles an optimized release binary and packages platform installers.

```bash
pnpm tauri build
```

Key options:
- `--debug`: Compiles with debug symbols while retaining production bundle settings.
- `--bundles <LIST>`: Builds only specified bundle formats (e.g. `--bundles deb,appimage`).
- `--target <TRIPLE>`: Cross-compiles for another target triple.

### Icon Generation (`tauri icon`)

Generates all required desktop and mobile icon sizes from a single 1024x1024 PNG source file.

```bash
pnpm tauri icon app-icon.png
```

Key options:
- `-o, --output <DIR>`: Specifies target output directory (defaults to `src-tauri/icons`).
- `--png <SIZES>`: Custom comma-separated PNG pixel dimensions.

### Environment Inspection (`tauri info`)

Prints system environment details, installed dependencies, webview versions, and Rust toolchain information.

```bash
pnpm tauri info
```

Use `tauri info` when debugging build failures or reporting issues.
