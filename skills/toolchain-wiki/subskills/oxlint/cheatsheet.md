## Decision rules

| When you need to                              | Do this                                              | Because                                              |
| --------------------------------------------- | ---------------------------------------------------- | ---------------------------------------------------- |
| gate lint in CI                               | `oxlint .` (`pnpm run lint`)                         | exits non-zero on errors; default deny correctness   |
| apply safe fixes locally                      | `oxlint --fix .`                                     | safe fixes only; no behavior change                  |
| preview risky fixes                           | `oxlint --fix-suggestions` then `--fix-dangerously`  | suggestions may change behavior; review first        |
| enforce zero warnings                         | `oxlint --max-warnings 0`                            | warnings become failures                             |
| inspect effective config                      | `oxlint --print-config src/file.ts`                  | shows merged config for one file                     |
| list all available rules                      | `oxlint --rules`                                     | exact count of 500+ ruleset                          |
| enable type-aware rules                       | `oxlint --type-aware` (tsgo, TS 7)                   | needs TS 7 native toolchain                          |
| allow one rule, deny a category               | `-A all -D no-debugger`                              | flags apply left-to-right; last wins                 |
| use a non-default config                      | `oxlint -c <path>`                                   | disables nested lookup; explicit wins                |
| skip nested config for speed                  | `oxlint --disable-nested-config`                     | only cwd lookup; single resolve                      |
| scaffold a starter config                     | `oxlint --init`                                      | writes `.oxlintrc.json` with defaults                |
| migrate from ESLint                           | `npx @oxlint/migrate`                                | converts ESLint config automatically                 |
| output for CI annotations                     | `oxlint -f github` (or `json`, `junit`)              | machine-readable formats for runners                 |

## Trade-off matrices

### --fix vs --fix-suggestions vs --fix-dangerously

| Flag                 | Safety        | When to use                              |
| -------------------- | ------------- | ---------------------------------------- |
| `--fix`              | Safe          | default local fix; no behavior change    |
| `--fix-suggestions`  | May change behavior | review each suggestion before applying |
| `--fix-dangerously`  | Dangerous     | codemods you fully understand            |

### -A vs -W vs -D

| Flag          | Level   | Exit code | When to use                          |
| ------------- | ------- | --------- | ------------------------------------ |
| `-A`/`--allow` | Off    | Zero      | suppress noisy rules per invocation  |
| `-W`/`--warn`  | Warning | Zero (unless `--deny-warnings`) | trial new rules without breaking CI |
| `-D`/`--deny`  | Error   | Non-zero  | enforce rules as gate                |

Flags apply left-to-right; last wins. `-A all -D no-debugger` allows all, then denies one.

### Config file formats

| Format              | Typing / autocomplete | When to use                              |
| ------------------- | --------------------- | ---------------------------------------- |
| `.oxlintrc.json`    | via `$schema`         | scaffold default; deterministic bytes    |
| `.oxlintrc.jsonc`  | via `$schema` + comments | hand-maintained configs with comments |
| `oxlint.config.ts` | `defineConfig`        | programmatic config; needs Node 22.18+   |

One config per directory; JSON and TS cannot mix.

### Categories: which to enable

| Category     | Strictness | When to use                                      |
| ------------ | ---------- | ------------------------------------------------ |
| `correctness`| Default on | always; catches wrong or useless code            |
| `suspicious` | Medium     | likely bugs; enable for review-heavy repos       |
| `pedantic`   | Strict     | occasional false positives; opt in per team      |
| `perf`       | Medium     | performance-sensitive code                       |
| `style`      | Low        | prefer oxfmt for style; use sparingly            |
| `restriction`| Opt-in     | ban specific patterns team-wide                  |
| `nursery`    | Unstable   | in development; expect churn                     |

## Tells and smells

### Tells (healthy)

- `pnpm run lint` passes on a clean checkout.
- `.oxlintrc.json` contains `$schema` plus `rules`.
- CI runs `pnpm run lint` as part of the verify gate.
- No `.eslintrc` remains after migration.

### Smells (problems)

| Smell                                  | Cause                                   | Fix                                              |
| -------------------------------------- | --------------------------------------- | ------------------------------------------------ |
| `pnpm run lint` fails after checkout   | violations committed without `--fix`    | run `oxlint --fix .`, commit result              |
| per-package lint drift                 | one config per dir; nested override     | check for nested `.oxlintrc.json`; use `-c`      |
| rule fires on generated files          | `ignorePatterns` missing                | add globs to config or `--ignore-pattern`        |
| type-aware rules do nothing            | tsgo missing or `typeAware` off         | set `options: { typeAware: true }`; use TS 7     |
| ESLint plugin behavior missing         | only built-in + alpha JS plugins        | check `jsPlugins` alpha; keep ESLint for that edge |
| slow lint in monorepo                  | nested config lookup per directory      | `oxlint --disable-nested-config`                 |

## Quick reference: CLI

| Command                                | What it does                              |
| -------------------------------------- | ----------------------------------------- |
| `oxlint .`                             | lint; CI gate                             |
| `oxlint --fix .`                       | apply safe fixes                          |
| `oxlint --fix-suggestions`             | apply suggestions (may change behavior)   |
| `oxlint --fix-dangerously`             | apply dangerous fixes                     |
| `oxlint --rules`                       | list all rules                            |
| `oxlint --print-config <file>`         | show effective config for one file        |
| `oxlint --type-aware`                  | enable type-aware rules (tsgo)            |
| `oxlint --init`                        | create starter `.oxlintrc.json`           |
| `oxlint -c <path>`                     | use explicit config; skip nested lookup   |
| `oxlint -f github\|json\|junit`         | machine-readable output for CI            |
| `oxlint --max-warnings 0`              | warnings become failures                  |
| `oxlint --quiet`                       | errors only                               |
| `oxlint --deny-warnings`               | warnings exit non-zero                    |
| `-A/-W/-D <rule\|category>`            | allow / warn / deny; last wins            |

## Quick reference: top-level config keys

| Key              | Purpose                                              |
| ---------------- | ---------------------------------------------------- |
| `rules`          | per-rule severity and options                        |
| `categories`     | enable groups by intent                              |
| `plugins`        | built-in plugins (import, react, jest, unicorn, etc.)|
| `jsPlugins`      | ESLint-compatible JS plugins (alpha)                 |
| `overrides`      | per-glob config                                      |
| `extends`        | inherit from other files                             |
| `ignorePatterns` | additional ignores                                   |
| `env`/`globals`  | predefined and custom globals                        |
| `settings`       | plugin-wide shared config                            |
| `options`        | linter-level: `typeAware`, `typeCheck`, `maxWarnings`|
