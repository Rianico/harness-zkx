# Markdown Flavour — Obsidian Default

Use Obsidian-flavoured markdown for `.md` files: wikilinks `[[Note]]`, callouts `> [!type]`, `==highlight==`, tags `#tag`/`#nested/tag`.

- Properties (`title`, `tags`, `date`, `aliases`, `cssclasses`) — only personal/task notes, never skill files or structured artifacts.
- Exceptions: scraped/external docs → standard markdown; SKILL.md frontmatter → `skill-conventions.md` (body still Obsidian).
- Deep syntax → `obsidian-markdown` skill.
