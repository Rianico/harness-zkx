COMPLETED: #266-seam-design-review-2 methodology findings (ai-engineering-expert & keel)

### Blockers

1. Unpinned `--status --json` and `transitions[]` schema invites immediate implementation drift
- Evidence: `docs/adr/0021-...md:35-37`; issue #266 item 1; `GLOSSARY.md:291-294`.
- Failure scenario: Neither ADR-0021 nor #266 pins the schema, field types, or structure for `--status --json` or `transitions[]` (e.g. types for `cost` and `preconditions`). Implementers will invent divergent schemas, breaking callers and test suites.
- Smallest fix: Pin the exact JSON schema and Python dataclasses for `--status` and `transitions[]` in the acceptance spec before dispatching implementation.

2. Undefined execution flow and exit code for reused draft PRs on mutating paths
- Evidence: `docs/adr/0021-...md:50-53`; issue #266 item 8; `skills/gh-router/subskills/pr-land/scripts/pr.py:470-479`.
- Failure scenario: #266 item 8 emits the ready-flip command "instead of a bare refusal". If mutating commands (`--merge`) do not refuse, their exit code is undefined: exiting 0 produces hallucinated completion; proceeding to watch skips CI; exiting 1 remains a refusal.
- Smallest fix: Explicitly specify that on mutating commands (`--watch`, `--merge`), encountering a reused draft halts with exit 1 and records `severity: refusal`, while read-only `--status` exits 0 with the ready-flip transition.

3. High-blast-radius rewrite coupling: atomic bugfixes bundled into architecture overhaul
- Evidence: `.agents/skills/keel/SKILL.md#L47-L54,L89-L93`; issue #266 items 1-9.
- Failure scenario: Standalone bugfixes with zero architectural coupling (item 5: remote branch parameterization; item 7: changelog push recovery; item 6: early title gate) are bundled with the 14-suite test migration and state machine rewrite. A regression in the state machine blocks the fixes.
- Smallest fix: Decouple into two tranches: Tranche 1 lands items 5, 6, 7 (isolated bugfixes); Tranche 2 lands items 1-4, 8, 9 (state derivation and artifact retirement).

### Major Findings

4. Scaffold `age` pushes mechanical freshness checks onto the semantic reasoner
- Evidence: `.agents/skills/ai-engineering-expert/SKILL.md#L46,L58-L62`; `docs/adr/0021-...md:43-44`; issue #266 item 3.
- Failure scenario: When a scaffold exists, the tool writes nothing and reports "its age". File modification time is a mechanical property. Asking the model to evaluate raw age forces the semantic reasoner to guess freshness that the formal substrate could check deterministically against HEAD commit time.
- Smallest fix: Report a deterministic boolean `stale` (e.g. scaffold mtime < HEAD commit timestamp) rather than raw age strings.

5. Exposing Python source `site` in refusal payloads induces unnecessary code exploration
- Evidence: `.agents/skills/ai-engineering-expert/SKILL.md#L96-L98`; issue #266 item 4; `docs/adr/0021-...md:47-48`.
- Failure scenario: `refusals[]` entries carry internal `site` pointers (e.g. `_squash.py:383`). LLM callers under context pressure mistake code sites for instructions to explore or edit `pr-land` source code, triggering hero-mode drift.
- Smallest fix: Scope `site` in `refusals[]` to user inputs or artifacts (`--title`, `--squash-message`, `pr_body.md:12`), reserving Python source sites for `--verbose`.

6. Unmanaged seam redundancy between `scripts/state.sh` and `pr.py --status`
- Evidence: `.agents/skills/keel/SKILL.md#L47-L54,L79-L80`; `skills/gh-router/scripts/state.sh:68-83`; issue #266 item 1.
- Failure scenario: `state.sh` (Phase 0 Orientation) and `pr.py --status` derive overlapping branch and PR states via divergent queries (`gh pr view` vs `gh api pulls`). Without a stated boundary, maintainers will update one and neglect the other.
- Smallest fix: State the boundary in `skills/gh-router/SKILL.md`: `state.sh` is human-facing quick terminal orientation; `pr.py --status` is authoritative machine-readable landing state.

7. Undeclared failure and recovery contracts for unavailable or unauthenticated `gh`
- Evidence: `.agents/skills/keel/SKILL.md#L95-L103`; `skills/gh-router/subskills/pr-land/scripts/_github.py:116-129,499-503`.
- Failure scenario: When `gh` is unauthenticated or the API is unreachable, `_github.py` crashes with unhandled `PrError` or `UsageError`. ADR-0021 does not define how `--status` or `refusals[]` structures environmental infrastructure failure.
- Smallest fix: Define an infrastructure refusal category (`severity: error`, `reason: gh auth invalid / network timeout`, `remedy: gh auth login`) so `--status` emits structured error data instead of crashing.

8. `GLOSSARY.md` architectural drift against updated ADR-0021
- Evidence: `GLOSSARY.md:283-286,296`; `docs/adr/0021-...md:48-58`.
- Failure scenario: `GLOSSARY.md:284` omits `pr_state`, `body_state`, and `worktree_clean`, and line 296 still lists `remote divergence` under judgment calls, contradicting revised ADR-0021 and #266.
- Smallest fix: Synchronize the `PR Landing State` and `Refusal Class` glossary definitions with ADR-0021.

### Minor Findings

9. Item 8 is a behavioral no-op for LLM callers
- Evidence: `.agents/skills/ai-engineering-expert/SKILL.md#L126`; `skills/gh-router/subskills/pr-land/scripts/pr.py:476-478`; issue #266 item 8.
- Failure scenario: `pr.py:476` already prints `remediation: PR #NUM is still a draft; run manually: gh pr ready NUM --repo REPO` on stderr and halts. Shifting this text into a JSON transition produces no measurable difference in agent behavior.
- Smallest fix: Treat item 8 as schema formatting rather than a functional behavioral change.

10. Undefined "cost" field in legal transitions
- Evidence: `.agents/skills/ai-engineering-expert/subskills/writing-for-agents/SKILL.md#L67-L73,L101-L102`; issue #266 item 1.
- Failure scenario: Requiring `cost` without defining its metric or schema produces arbitrary strings (`low`, `network`), adding tokens without decision value.
- Smallest fix: Drop `cost` or constrain it to an explicit enum: `mutation: none | local | remote`.
