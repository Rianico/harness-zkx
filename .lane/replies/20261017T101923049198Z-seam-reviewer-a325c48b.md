COMPLETED: #266 seam design review findings (ADR-0021)

### Blockers

1. Contradiction on remote divergence handling between ADR-0021 and #266
- Evidence: `docs/adr/0021-...md:47-48` vs `gh issue view 266` item 5.
- Failure scenario: ADR-0021 classifies remote divergence as a judgment call emitting state/transitions without refusing. #266 item 5 explicitly orders refusal (exit 1) on remote divergence.
- Smallest fix: Align ADR-0021 and #266: treat divergence as RefusalError on mutation paths (`--watch`, `--merge`, auto-push), but emit state without refusing under read-only `--status`.

2. Stale scaffold leak across branches remains unfixed under un-scoped leaf policy
- Evidence: `docs/adr/0021-...md:38-43`, `gh issue view 266` item 3, `_draft.py:458-462`.
- Failure scenario: Switching from branch A to B leaves `.lsz/gh-router/pr_body.md`. When body-less `--check` runs on B, the existing leaf causes it to write nothing. Running `pr.py --body-file .lsz/gh-router/pr_body.md` submits branch A's description on branch B.
- Smallest fix: Default the scaffold leaf name to the branch slug (e.g. `.lsz/gh-router/<head_ref_slug>.md`) rather than a single static path.

3. Push precondition violates read-only contract during `--check` and `--status`
- Evidence: `gh issue view 266` item 5, `_check.py:81`, `pr.py:663`.
- Failure scenario: #266 item 5 executes push before `gh api pulls`. Both `--check` and `--status` call `gh api pulls`. Pushing there mutates remote state during read-only preflight and inspection commands.
- Smallest fix: Restrict the auto-push precondition strictly to the PR creation path in `create_or_reuse_pr`.

4. Non-idempotent `stamp_changelog` strands local commit if push fails
- Evidence: `skills/gh-router/subskills/pr-land/scripts/_changelog.py:125,217-222`.
- Failure scenario: If `git commit` succeeds during changelog stamping but `git push` fails, a rerun finds `(#NUM)` already in `CHANGELOG.md` and returns `False` at line 126. The commit remains unpushed and CI fails remotely.
- Smallest fix: In `stamp_changelog`, if `(#NUM)` exists in `CHANGELOG.md`, check if local branch is ahead of remote; if ahead, push before returning.

### Major Findings

5. Incomplete PR landing state machine coverage
- Evidence: `docs/adr/0021-...md:49-51`, `GLOSSARY.md:283-286`, `_check.py:93-95`.
- Failure scenario: 1) `pr_exists` is boolean; an existing merged PR makes `pr_exists` false under open-only query, triggering failing 422 `POST pulls`. 2) No predicate tracks body readiness (`body_ready`, `sentinels_unfilled`). 3) Uncommitted dirty worktree is unrepresented.
- Smallest fix: Expand predicates with `pr_state` (`none` | `open` | `merged` | `closed`), `body_state` (`none` | `scaffold` | `unfilled` | `ready`), and `worktree_clean`.

6. Deletion of `draft.json` destroys derived squash message preview
- Evidence: `docs/adr/0019-...md:35-37`, `docs/adr/0021-...md:35-37`, `_draft.py:334,499`.
- Failure scenario: ADR-0019 mandates `--check` preview the derived squash message. Currently `draft.json` stores this preview. Deleting `draft.json` leaves no output destination for the preview.
- Smallest fix: Include `squash_body_preview` in `--status --json` output, or output a dedicated preview artifact.

7. Hardcoded `origin` in `_remote_branch_exists` breaks non-origin push remotes
- Evidence: `skills/gh-router/subskills/pr-land/scripts/_github.py:290-296`.
- Failure scenario: If a branch uses a fork or non-origin remote via `repo_remote_for_ref`, `_remote_branch_exists` checks `refs/remotes/origin/{name}`, falsely reporting missing remote refs.
- Smallest fix: Parameterize `_remote_branch_exists(remote, name)` using the remote resolved by `repo_remote_for_ref`.

8. Rate-limit fake clock scope is insufficient across test suite
- Evidence: `skills/docs-scraper/scripts/scrapers/base.py:183,275`, `tests/docs-scraper/test_robots_compliance.py:289`, `tests/docs-scraper/test_retry_after.py:105,149`.
- Failure scenario: 1) `test_rt_05_crawl_delay_directive` uses unmocked `time.time()` in `_wait_for_rate_limit` and flakes under latency. 2) `test_ra_02_retry_after_http_date` calculates `dt.timestamp() - time.time()`; patching `time.time` without synchronizing `datetime.now(UTC)` causes disparity against the 60s cap.
- Smallest fix: Use `time.monotonic()` in `base.py:183`, synchronize `datetime.now(UTC)` with fake clock in HTTP-date tests, and share the fixture with `test_robots_compliance.py`.

9. Unaccounted deletion fallout across tests and sibling skills
- Evidence: `tests/gh-router/test_pr_draft_phase.py`, `tests/gh-router/test_pr_enhance_retirement.py:125-138`, `skills/gh-router/subskills/pr-refine/SKILL.md:25`, `skills/gh-router/SKILL.md:35`.
- Failure scenario: Deleting `draft.json`, `DRAFT_OUT_DIR`, and `--out-dir` breaks 6 test suites and leaves `pr-refine` and `SKILL.md` pointing to obsolete paths.
- Smallest fix: Expand #266 migration list to cover `test_pr_draft_phase.py`, `test_pr_enhance_retirement.py`, `test_pr_attribution.py`, `test_pr_squash_copy.py`, `test_pr_squash_gate.py`, `test_pr_land_range_authority.py`, and sibling docs.

### Minor Findings

10. Reused draft PR transitions create automated execution dead-end
- Evidence: `skills/gh-router/subskills/pr-land/scripts/pr.py:470-479`, `gh issue view 266` item 8.
- Failure scenario: Emitting a manual `gh pr ready` command when encountering a reused draft stops execution and blocks automation.
- Smallest fix: Support `--ready` on `pr.py` (or allow `--no-draft` on reused PRs) so scripts can ready the PR directly.

11. Deferring title validation to merge phase wastes watch cycle
- Evidence: `skills/gh-router/subskills/pr-land/scripts/pr.py:675,758`, `skills/gh-router/subskills/pr-land/scripts/_github.py:372-391`.
- Failure scenario: Titles exceeding 100 characters are validated only at merge time. PR creation and a 10-minute watch complete before aborting at merge.
- Smallest fix: Run `check_squash_title(title, 9999)` before `create_or_reuse_pr` when `--merge` is passed.

12. Blanket changelog stamping risks multi-bullet over-attribution
- Evidence: `skills/gh-router/subskills/pr-land/scripts/_changelog.py:157-188`.
- Failure scenario: `stamp_changelog` appends `(#NUM)` to every unstamped bullet in `## [Unreleased]`, conflating unrelated changes.
- Smallest fix: Restrict auto-stamping to entries matching commits in the PR range or the PR conventional commit scope.
